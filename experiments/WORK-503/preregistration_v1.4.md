## 0. 一句话：v1.3 的**冻结判定规则不变**，但 v1.3 §4 给出的「两种口径判词逐点相同」这个**论证是错的**，本版把它更正为正确的论证

**触发**：v1.3 落盘后立刻补的边界单测（`scripts/work503_test_verdict.py`，T2）**当场判红**：
在 −0.60 ~ +0.60 的 121 个网格点上，v1.3 §4 声称的「逐点相同」只有 71 个点成立。

**错误出在哪**：v1.3 §4 写「进带互为相反数 → 两种口径逐点相同」。实际上
`[−0.40, −0.15]` 取负是 `[+0.15, +0.40]`，**这两个集合不相等**；
只有**退带** `[−0.10, +0.10]` 关于 0 对称，取负后不变。
所以 v1.3 §4 的结论「本修订在数学上不可能翻转任何判词」是**错的**——它只对退带成立，对进带不成立。

**时点**：该错误是在**任何正式模型结果产生之前**被单测抓出来的（正式训练仍在跑，仓库里只有一个 1-epoch 冒烟产物）。
**冻结的判定规则本身没有因此改变**（仍是 v1.3 §3 的那一条），改变的是**论证**。

## 1. 派单卡三句话仍然互相矛盾（这一点 v1.3 说对了）

| # | 原文（派单卡 / v1.0 §9） | 算术核对 |
|---|---|---|
| ① | 定义 `Δ_ic = (RankIC_full − RankIC_no_vq) / RankIC_full` | 分式照此写 |
| ② | 论文基准：0.0646 → 0.0472，即 `Δ_ic = −26.9%`（Table 2） | (0.0646 − 0.0472)/0.0646 = **+26.9%**，符号与 ② 相反 |
| ③ | **进**：`Δ_ic` 落在 **[−40%, −15%]**；**退**：落在 **[−10%, +10%]** | 把 ① 代入论文数字得 +26.9%，落在两条带**之外** → 判「部分复现」 |

**关键推论（v1.4 的核心论证）**：照 ①+③ 原样实现，**论文自己报的结果会被判成「部分复现」**。
一个用来判断「论文结论有没有被复现」的协议，在论文自己的数字上给出「部分复现」，说明 ① 与 ③ 不可能同时是本意。

## 2. 两种自洽的读法，以及它们与字面读法的关系

记 `Δ_formula = (RankIC_full − RankIC_no_vq)/RankIC_full`，`Δ_drop = −Δ_formula`。

| 读法 | 判词量 | 进带 | 退带 | 论文自己的数字（full 0.0646 / no_vq 0.0472）判成 |
|---|---|---|---|---|
| **A（v1.3 / 本单采用）** | `Δ_drop` | `[−40%, −15%]`（原文逐字） | `[−10%, +10%]`（原文逐字） | **进**（Δ_drop = −26.9%，落在进带） |
| **B（等价写法）** | `Δ_formula` | `[+15%, +40%]`（进带取反） | `[−10%, +10%]`（不变） | **进**（Δ_formula = +26.9%） |
| **C（v1.0 字面）** | `Δ_formula` | `[−40%, −15%]`（原文逐字） | `[−10%, +10%]`（原文逐字） | **部分复现**（+26.9% 落在两条带之外） |

- **A 与 B 逐点等价**（对任意实数 Δ_formula 给出同一个判词）：进带互为相反数、退带对称、部分复现取补集。
  → 可执行证明见 `scripts/work503_test_verdict.py` 的 T2（网格 + 端点对）。
- **C 与 A 不同**：分歧只在「码本带来 15%~40% 的增量」这一段——C 把它判成「部分复现」，A/B 判成「进」。
  在退带（|Δ| ≤ 10%，即码本没效果）上 **C 与 A 完全一致**，都判「退」。
- **为什么选 A 而不是 C**：C 会让「复现成功」这个结论**不可达**——码本真的有效（full > no_vq）时 Δ_formula > 0，永远落不进进带。
  派单卡把 ②「论文基准 −26.9%」与 ③「进带」并排列出，只有 A 能同时满足它们。

## 3. 本版冻结的口径（与 v1.3 §3 完全一致，未改动）

1. **判词用的量**：`Δ_drop = (RankIC_no_vq − RankIC_full) / RankIC_full`，取各档 ≥2 个种子的**中位数**。
2. **判词带逐字不动**：进 `[−40%, −15%]`；退 `[−10%, +10%]`；其余 → 部分复现。
3. **并列报告**：`Δ_formula`（派单卡 ① 的字面式，论文 = +26.9%）与 `Δ_drop`（判词用，论文 = −26.9%）。
4. **失败判据 3**（两个种子都落在 [−10%,+10%] → 判退）按 `Δ_drop` 执行；该带对称，两种口径取值相同。
5. H2 / H3 / 成本 / 组合规则 / 股票池 / 标签 / 种子 / 训练段 / 轮数 / 掩码语义：**逐字未动**。

## 4. 对「这不是结果驱动的改协议」的正面回答

| 追问 | 回答 |
|---|---|
| 阈值被放宽了吗？ | **没有**。进带的宽度（25 个百分点）、绝对值（15%、40%）、退带（±10%）全部逐字未动；被重新定义的是**被测量的量**，不是阈值。 |
| 会被用来把失败调成通过吗？ | **不会**。若本单跑出「码本让 RankIC 提升 15%~40%」，A/B 判「进」、C 判「部分复现」；若跑出「码本无效果」（|Δ| ≤ 10%），A/B/C **都**判「退」。A 相对 C 只会把「码本确实有用」的结果判得更肯定，**不会把失败判成通过**；而失败判据 3（两个种子都平）独立地判退，不受影响。 |
| 看过结果才改的吗？ | **没有**。v1.3（15:06）与本版（正式结果之前）落盘时，正式训练尚未跑完、任何正式模型的 RankIC 都还不存在；错误由单测当场抓出，而非由结果触发。 |
| 判词口径有没有被事后调过？ | 没有。v1.0 → v1.3 → v1.4 三版之间，**进/退两条带的数字一次都没有变过**。 |
| 为什么不干脆改公式、保留原带（= C）？ | 因为 C 会让「复现成立」这个结论在协议层面不可达（§2 末），与派单卡同时写出的「论文基准 −26.9%」直接冲突。 |
