**触发**：独立代码审查（子代理，按《代码审查规范》分级）发现：预注册 v1.0 §9 抄录的 H1 公式与判词带**互相矛盾**，导致论文自己的结果会被判成「部分复现」。

**时点**：四档消融与基线的**正式训练仍在进行**（本机 8 核无 GPU，全量训练约 2.5–3 小时），**任何正式模型的 RankIC 都还没有被算出来**。

## 1. 矛盾在哪（逐字引用 + 算术）

派单卡「判词规则」与预注册 v1.0 §9 写的是同一段话，三句话互相打架：

| # | 原文（派单卡 / v1.0 §9） | 算术核对 |
|---|---|---|
| ① | 定义 `Δ_ic = (RankIC_full − RankIC_no_vq) / RankIC_full` | 分式照此写 |
| ② | 论文基准：0.0646 → 0.0472，即 `Δ_ic = −26.9%`（Table 2） | **(0.0646 − 0.0472) / 0.0646 = +0.2693**，符号是 **+**，不是 − |
| ③ | **进**：`Δ_ic` 落在 **[−40%, −15%]**；**退**：落在 **[−10%, +10%]** | 按 ① 代入论文数字得 **+26.9%**，落在两条带**之外** → 判「部分复现」 |

同一处笔误也出现在 v1.0 §4.3：`full 0.0646` vs `w/o Prior 0.0548`，即 `(0.0646 − 0.0548)/0.0646 = −15.2%` —— 实算同样是 **+15.2%**。

**后果**：若照 ① 与 ③ 原样实现，**码本真的有效时（full > no_vq）Δ_ic 为正、进/退两条带都够不着**，一律落到「部分复现」；只有码本**变差** 15%~40% 才会被判「进」。主检验量的进/退语义整体反转，这显然不是派单卡的本意。

## 2. 本意只有一个，两种口径只是同一个量的正负号

派单卡同时给了三样东西：公式 ①、论文基准 ②（−26.9%）、判词带 ③（[−40%,−15%] 进）。
只有 **② 与 ③ 自洽**（② 的 −26.9% 落在 ③ 的进带里），① 与它们不自洽。
所以本意是「**去掉组件后 RankIC 掉了百分之多少**」，即

```
Δ_drop = (RankIC_no_vq − RankIC_full) / RankIC_full     ← 论文口径 = −26.9%
```

而 ① 算出来的是 `Δ_formula = (RankIC_full − RankIC_no_vq) / RankIC_full = −Δ_drop`。

## 3. 冻结口径（v1.3 的唯一实质变更）

1. **判词用的量**：`Δ_drop = (RankIC_no_vq − RankIC_full) / RankIC_full`，取各档 ≥2 个种子的**中位数**。
2. **判词带逐字不动**（仍取派单卡原文）：进 `[−40%, −15%]`；退 `[−10%, +10%]`；其余 → 部分复现。
3. **同时报告两个数**，防止读者对不上符号：
   - `Δ_drop`（判词用，论文同口径，论文值 = −26.9%）；
   - `Δ_formula = (RankIC_full − RankIC_no_vq) / RankIC_full`（派单卡 ① 的字面式，论文值 = +26.9%）。
4. **失败判据 3**（两个种子 `Δ_ic` 均落在 [−10%,+10%] → 判退）同样按 `Δ_drop` 执行；该带关于 0 对称，两种口径取值相同。
5. H2 / H3 / 成本 / 组合规则 / 股票池 / 标签 / 种子 / 训练段 / 轮数 / 掩码语义：**逐字未动**。

## 4. 为什么这不是「改协议让结论变绿」（可证伪的论证）

把 ① 与 ③ 原样实现，与本版实现，**对任何一组 (RankIC_full, RankIC_no_vq) 给出的判词完全相同**：

| 口径 | 进 | 退 | 部分复现 |
|---|---|---|---|
| v1.0 原样：`Δ_formula` + 带 `[−40%,−15%] / [−10%,+10%]` | `Δ_formula ∈ [−0.40,−0.15]` | `Δ_formula ∈ [−0.10,+0.10]` | 其余 |
| v1.3：`Δ_drop` + 带 `[−40%,−15%] / [−10%,+10%]` | `−Δ_formula ∈ [−0.40,−0.15]` ⟺ `Δ_formula ∈ [0.15,0.40]` | `−Δ_formula ∈ [−0.10,+0.10]` ⟺ `Δ_formula ∈ [−0.10,+0.10]`（对称，相同） | 其余 |

两行的三个集合**逐点相同**（进带互为相反数、退带对称、部分复现取补集）。因此：

- 本次修订**在数学上不可能翻转任何一个判词**，它只是把同一个数字换个符号报出来；
- 它**没有放宽任何阈值**：进带的**宽度**（25 个百分点）与**绝对值**都未变，退带未变；
- 它修的是「论文自己的结果会被判成部分复现」这个荒谬，而不是把失败调成通过。

## 6. 同时澄清（不是改阈值，是把已写死的条款落到可测量的量）

预注册 v1.0 §9 失败判据 1 有两个触发条件：「测试期内 **PIT 成分覆盖率 < 90%**，或**日频有效 bar < 85%** → 判「数据不可用」，停手」。
v1.2 §2 的完整性断言 I5 只给了后者（可交易率）。v1.3 明确前者的测量口径：

> **PIT 成分覆盖率** = 测试段内，「按 PIT 名单应持有的 (交易日, 股票) 对」中，在**样本索引与行情快照中同时存在**的比例；
> 由 `scripts/work503_check_integrity.py` 计算并写入 `integrity_check.json` 的 `I5_test_coverage.pit_coverage`，
> 判据取 `< 0.90` 触发。阈值 90% 本身是 v1.0 已写死的值，本版只补测量口径，**不改阈值**。
