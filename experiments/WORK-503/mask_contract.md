## 2. 停牌（suspended）

**规则（字段字典 §5「停牌」行）：个股停牌日保留行、价格前向填充到上一收盘、成交量置 0；不得删除行。**

实现：

1. 原始层：新浪财经在停牌日**不返回行**。落盘后按交易日历 reindex，缺失日即停牌日。
2. 加工层：价格列（open/high/low/close）在停牌日按字段字典 §5 **前向填充到上一收盘**；`volume = 0`，`amount = 0`；`tradable = False`。
3. 样本层：停牌日**保留样本**（价格不动 → 特征无新信息），但不进入可交易集合。
4. 前视检查：前向填充只用 ≤ t 的数据；特征窗口取 t-19 ~ t，窗口内停牌日已 ffilled，不含未来信息。

## 3. 涨跌停（limit up / limit down）

**规则（字段字典 §5「涨跌停」行）：涨跌停日不得成交，回测中该日下单量按 0 处理；不得假设能买到。**

实现（基于**不复权**价）：

1. `pre_close_raw(t) = close_raw(t-1)`；当日为停牌日时不产生涨跌停判定（`limit_up = limit_down = False`，但 `tradable = False`）。
2. 涨跌幅限（percent）：主板 `60xxxx / 00xxxx` = 10%；创业板 `30xxxx` = 20%；科创板 `688/689` = 20%；北交所 `8/4` 开头 = 30%。
3. **ST 保守处理**：本轮没有可用的历史 ST 标记（接口不提供逐日 ST 状态），因此对每个板块**同时**使用「该板块正常限」与「ST 限 5%」两个候选限：
   - `limit_up(t) = close_raw(t) >= pre_close_raw(t) × (1 + b) − 0.005`，对 b ∈ {板块限, 5%} 取**或**；
   - `limit_down(t) = close_raw(t) <= pre_close_raw(t) × (1 − b) + 0.005`，同上。
   - 含义：**宁可多掩码，不可漏掩码**。代价是非 ST 股票当日恰好走出 ±5% 会被误掩码（该日不可买），属于保守偏差，方向上只会削弱组合收益，不会虚增。
   - 该规则的**误掩码比例**在 §7 报告中量化（测试期 PIT 样本中的 limit_up 占比）。
4. 交易规则：
   - **买入**：涨停日不可买（`limit_up = True` → 从候选 Top-K 中剔除）。
   - **卖出**：跌停日不可卖（`limit_down = True` → 当日不执行卖出，回调引擎中该持仓权重不变并顺延到下一可交易日）。卖不出的处理必须与买入不同：涨停是「买不进」，跌停是「卖不出」。

## 4. 退市清算（delisting）

**规则（字段字典 §5「退市」行）：退市股票在退市日必须保留到最后交易日；退市后从次一交易日起移出股票池。不得回溯剔除。**

实现：

1. 股票池来自 **PIT 成分名单**（`pool_membership.csv`，145 个生效名单，2012-01-30 ~ 2024-12-30）。名单按生效日生效、向后沿用至下一生效日。
2. 退市股票在**其最后有行情的交易日之后**自然离开名单（名单变更时移出），实现上不依赖任何「退市名单」字段，**结构上不存在幸存者偏差回填**。
3. 持仓中的退市股票：在其最后交易日按最后收盘价**强制平仓**（清算），实现为「持仓 → 现金」的一次性换仓，成本按卖出侧 15 bps 计。
4. 幸存者偏差体检：`experiments/WORK-503/data_probe.json` 中 Tushare `stock_basic(list_status="D")` 的 330 条退市名录作为**独立对照**，检查 PIT 名单是否遗漏了曾经是 CSI300 成分、期间退市的股票。

## 5. 新股与次新

**规则（字段字典 §5「新股上市」行）：上市首日排除；按「上市满 N 个交易日」过滤，N 预先写死。**

- 本单：**N = 20**（与特征回看 T = 20 一致；不足 20 个交易日的股票不作为样本，因其特征窗口不完整）。
- 实现：样本要求该股至少有 20 个交易日的连续行情；不满足则该 (股, 日) 不入样本。

## 6. 涨跌停与停牌的交互

| 状态 | 买入 | 卖出 |
|---|---|---|
| 正常 | 允许 | 允许 |
| 停牌 | 不允许（无可成交价） | 不允许（顺延） |
| 涨停 | **不允许** | 允许 |
| 跌停 | 允许 | **不允许（顺延到下一可交易日）** |

## 7. 回测引擎断言（必须真的在跑）

回测引擎内置断言：

1. `assert_not_limit_up`：任一**买单**若对应标的当日 `limit_up = True` → 抛错。
2. `assert_not_suspended`：任一**买单/卖单**若对应标的当日 `suspended = True` → 抛错。
3. `assert_price_available`：任一成交若使用了停牌日的（填充）价格 → 抛错。
4. `assert_weight_sum`：任一调仓日的组合权重和与 1 的偏差 > 1e-9 → 抛错。
5. `assert_no_future`：任一特征/先验若引用了 > t 的数据 → 抛错（由滞后构造保证，运行时抽查）。

**必须用故意违规开关触发一次**（`WORK503_ASSERT_VIOLATION=1`），把告警原文贴进交付评论 —— 见交付物 #4。

## 8. 本契约与字段字典的关系

- 本契约**只落地**字段字典 §5 已有的原则，**不新增、不放宽**任何既有规则。
- 唯一需要大管家转用户定的并入项：字段字典 §5 目前对个股的涨跌停限值没有写死具体百分比（主板/创业板/科创板/北交所分别是 10%/20%/20%/30%，ST 5%），本契约 §3 把这些数值写死。**建议并入**；是否并入请大管家转用户定。
- 另有一项待并入：字段字典 §1/§2 面向指数，个股的复权口径（后复权 = 特征与组合收益用；不复权 = 涨跌停判定用）尚未在字典中登记，本契约 §1 已写死，建议并入。
