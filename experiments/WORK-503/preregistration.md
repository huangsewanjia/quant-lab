## 0. 一句话核心假设与可证伪判词

**核心假设**：PRISM-VQ 的离散码本（VQ codebook）在 CSI300 横截面预测中带来**可测量的增量**，

## 4. 先验因子：两档（写死）

### 4.1 主档（full / no_moe / no_vq 都用这档）

6 个自建 A 股可得先验，全部**滞后一个交易日**（只用 ≤ t−1 的信息，与论文「computed using information available up to t−1」一致）：

| # | 因子 | 定义 | 字段来源 | 方向 |
|---|---|---|---|---|
| P1 | `mkt_20d` | 沪深300 收盘(t−1)/收盘(t−21) − 1 | `index_sh000300.csv` | 全市场共同暴露（正=市场上涨） |
| P2 | `size_lm` | ln(流通市值(t−1))，流通市值 = 流通股本 × 不复权收盘价 | 新浪财经 `outstanding_share` × close | 正=大市值 |
| P3 | `value_bp` | 每股净资产(生效值) / 不复权收盘价(t−1) | 新浪财经·财务指标 `每股净资产_调整后`，报告期 + 120 天生效 | 正=高账面市值比（便宜） |
| P4 | `mom_12_1` | 后复权收盘(t−21) / 后复权收盘(t−252) − 1 | 后复权价 | 正=中期动量 |
| P5 | `vol_60d` | 过去 60 日日收益标准差 × √252 | 后复权价 | 正=高波动 |
| P6 | `rev_5d` | 后复权收盘(t−1) / 后复权收盘(t−6) − 1 | 后复权价 | 正=短期涨幅（反转方向为负向暴露） |

- P1 为全局因子，按交易日广播到全部股票；P2–P6 为逐股因子。
- 先验进入模型前做 `RobustZScoreNorm + Fillna`（与 feature 同口径，拟合窗口 = 训练段）。

### 4.2 对照档（no_prior）

先验输入**全部置零**（维度保持 6，其余一切不变：数据、特征、种子、切分、组合规则、成本完全一致）。

### 4.3 论文「去先验掉 15.2%」的对照口径

论文 Table 2：`full 0.0646` vs `w/o Prior 0.0548`，即 `Δ = (0.0646 − 0.0548)/0.0646 = −15.2%`。
本单用**主档（自建先验）vs 对照档（无先验）**对齐这一量，两者同为「有先验 vs 无先验」，口径可比。

## 5. 标签与成本（写死）

### 5.1 标签

- 主目标：**5 日前瞻收益 `open(t+1) → close(t+5)`**，`y = close(t+5)/open(t+1) − 1`（与论文正文 §5.1.1 及本单要求一致）。
- 辅助目标：`k = 1..10` 的 `open(t+1) → close(t+k)`，权重 `aux_weight` 同上游配置。
- 训练时标签做 `CSRankNorm`（按日横截面秩归一），与上游一致。
- 模型预测目标位次 `target_day = 5`（上游配置）。

### 5.2 成本

| 档 | 买入（开盘） | 卖出（收盘） | 用途 |
|---|---|---|---|
| **主口径** | **5 bps** | **15 bps** | 所有主检验量 |
| 敏感性 1 | 8 bps | 8 bps | 单边 8 bps |
| 敏感性 2 | 15 bps | 15 bps | 双边 30 bps |

- 成本计入**净收益**后再算 AR / MDD / SR / 换手（不得先算毛指标再扣）。
- 换手口径：**日均单边换手**（当日买入权重 + 当日卖出权重，再除以 2），与论文 Table F.1「mean daily turnover」对齐。

## 6. 组合构造（写死）

- 策略：**TopK-DropN**，K = 30，N = 5（论文 §5.1.3 / 附录 D）。
- 只做多；等权；调仓**每个交易日**；组合始终持有 30 只（不足 30 只可交易标的时持有全部并等权）。
- 执行时序（与 Qlib `TopkDropoutStrategy` 一致）：
  - 以 t 日收盘后可得的信号 ŷ_t 排序；
  - t 日**收盘**卖出最多 N = 5 只持仓中信号最低者（卖价 = 收盘价，成本 15 bps）；
  - t+1 日**开盘**买入等量更高排名的候选（买价 = 开盘价，成本 5 bps）；
  - 持仓股票在 t → t+1 区间按收盘价对收盘价计收益；新买入股票只承担 open(t+1) → close(t+1) 的收益。
- 掩码：涨停不可买、停牌不可交易、跌停不可卖（顺延）、退市清算 —— 见 `mask_contract.md`。
- 基准调整 alpha：
  - **CSI300 等权**：测试期 CSI300 成分的等权组合日收益；
  - **CSI300 市值加权**：以 PIT 成分名单的权重（若不可得则用流通市值加权，权重口径写进报告）计算的日收益；
  - 两档都报：超额年化、超额信息比（IR）、跟踪误差。

## 9. 主检验量与阈值（原样抄进判词规则，跑完不许改）

主检验量 **H1（码本有效性，唯一决定进/退的量）**：

- 定义 `Δ_ic = (RankIC_full − RankIC_no_vq) / RankIC_full`，取各档 ≥2 个种子的**中位数**。
- 论文基准：0.0646 → 0.0472，即 `Δ_ic = −26.9%`（Table 2）。
- **进**：`Δ_ic` 落在 **[−40%, −15%]** → 判「码本有效性复现成立」。
- **退**：`Δ_ic` 落在 **[−10%, +10%]** → 判「未复现」，卡在码本无增量这一条。
- **部分复现**：其余区间 → 判「部分复现」，必须写清偏差来自哪一项（数据起点 / 先验因子替换 / 掩码 / 成本），并给出翻案条件。

并列检验（不单独决定进/退，但必须报，且必须与 H1 结论一起出现）：

- **H2 增量显著性**：完整模型 vs 固定基线 **GRU**（预注册固定，不在测试段挑基线）的 RankIC 差，**10000 次 block bootstrap**（block 长度 5 个交易日）的 95% CI。论文自曝对 DTML/GRU 未达显著——若我们 CI 含 0，判「与论文自曝弱点一致」，**不算失败**，但报告里必须写「本方法的增量在统计上不可证」。
- **H3 可交易性**：净 SR / AR / MDD / 日均换手（论文 SR 1.5694、AR 0.3077、MDD 0.1924、换手 0.3259）。净 SR 的 95% CI 下界 > 0 且相对论文缩水 ≤60% → 可交易性成立；**净 SR < 0 → 直接判退**，与 H1 无关。

失败判据（预先写死，命中哪条就写哪条）：

1. 测试期内 PIT 成分覆盖率 <90%，或日频有效 bar <85% → 判「数据不可用」，停手，不硬跑。
2. 任一必需端点 403/40203 且无合规替代 → 停。
3. 两个种子 `Δ_ic` 均落在 [−10%, +10%] → 判退。
4. 预注册 commit 时间晚于第一个回测产物的 commit 时间（`git log` 可查）→ 整单结论作废，重跑。
5. 独立复算与建模侧相对差 >1e-6 → 以复算值重出判定，并在报告里列出全部不一致项。

种子报告规则：**必须报 mean ± range，不许只报最好的一次**；只报单种子结果的判定按未交付处理。

## 10. 指标定义（写死）

按论文附录 C：

- **RankIC(t)** = 当日预测分数与实现收益的**秩相关**（对两侧取秩后求 Pearson 相关）；`RankIC` = 测试期日均。
- **RankICIR** = `mean(RankIC_t) / std(RankIC_t)`（**不做年化**）。
- **组合日对数收益** `g_p,t = log(1 + Σ w_i,t · y_i,t)`，其中 `y_i,t` 为持仓在 t 日实现的价格收益。
- **AR** = `exp(252 · mean(g_p,t)) − 1`；**MDD** = `max(1 − W_t / max_{s≤t} W_s)`；**SR** = `√252 · mean(g_p,t) / std(g_p,t)`，无风险利率取 0。
- 所有组合指标在**扣除成本后**计算。
