## 1. 计时基准证据（本次修订的唯一依据）

一次性计时探针（**只测吞吐，不产生任何回测数字，不产生任何模型产物**），在 `vendor/PRISM-VQ` 的官方模型代码上跑合成张量：

| 项 | 实测 |
|---|---|
| stage-1（`trainer/train_vqvae.py: FactorVQVAE`）单步 fwd+bwd，batch = 300 × 20 × 158 | **0.33 / 0.39 / 0.67 s**（3 次） |
| stage-2（`trainer/train_ypred_wo_stage1.py: GenerateReturn`）单步 fwd+bwd | **0.05 / 0.06 / 0.15 s**（3 次） |
| CPU | 8 核，无 GPU；`torch.set_num_threads(8)`，float32 |
| 配置 | CSI300 口径：`n_expert=2, k=1, num_heads=2, aux_weight=0.01, num_prior_factors=6`（本单先验维度改为 6，见 v1.0 §4） |

据此估算（每 epoch = 训练段交易日数个 batch）：

| 组合 | 步数/轮 | 6 轮耗时 | 次数 | 小计 |
|---|---|---|---|---|
| stage-1（full / no_moe / no_prior 共用同一次 stage-1，见 §13） | 1220 | ~49 min | 2（每种子一次） | ~1.6 h |
| stage-2（带码本：full / no_moe / no_prior） | 1220 | ~24 min | 6 | ~2.4 h |
| stage-2（no_vq，无码本） | 1220 | ~10 min | 2 | ~0.3 h |
| GRU 基线（`qlib.contrib.model.pytorch_gru_ts.GRU`） | 1220 | ~10 min | 2 | ~0.3 h |
| **合计（顺序执行）** | | | | **~4.6 h** |
