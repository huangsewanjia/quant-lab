## 0. 一句话核心假设与可证伪判词

**核心假设**：把 A 股 20 日 K 线图用**未经金融监督**的 DINOv2-S 编码后，在**递归扩张的历史图表库**中检索
余弦近邻，以邻居的**已实现后续 5 日收益**均值作为横截面信号，该信号在 CSI300 池上产生**成本后仍为正**
的多头超额收益。

**唯一决定进/退的量**：§7 的 H1（阶段 A、K=1000、净 Sharpe，A 股可执行口径）。
其余检验量（H2/H3/H4）并列报告，只在 H2 符号反转时行使否决权。

## 2. 股票池（写死）

- **池 = PIT CSI300**：`index_weight` 表 `index_code='000300.SH'`，实测 **250 份月度快照**
  （2006-01-25 ~ 2026-10-30），每份 300 只。
- **as-of 规则**：日期 d 的成分 = 满足 `snapshot_date <= d` 的**最后一份**快照的 300 只；
  快照不存在早于 d 的样本直接剔除。**禁止**用当前名单回填历史（前视偏差）。
- **最小上市天数**：图表日 t 时，该股在 `daily` 中已出现的交易日数（以 SSE 交易日历计）≥ **250**。
- **图窗口完整性**：t 的 20 日窗口内该股在 `daily` 必须**逐日有行**（停牌缺行即弃）；MA20 额外需要的
  19 个前置交易日同样必须逐日有行。缺一行即该 (股, t) 不产生图，不做前向填充（`field_dictionary.md` §6）。
- 单票权重上限：**等权 = 1/30**（多头 30 只时）；不设额外压缩。

## 4. 检索口径（写死）

- **库**：所有 (股票 j, 周 τ) 图中，其标签窗口已完全实现的那些。形式化：设 `idx(·)` 为 SSE 交易日序号，
  查询日 t 的可用库 = `{(j,τ) : idx(τ) + 6 <= idx(t)}`。
- **递归扩张**：库只增不减；不设滚动画窗（论文 Table 6 的 Rolling 8Y 不在本单复现）。
- **相似度**：L2 归一化后的内积 = 余弦（论文式 (2)）。**精确** top-K（`faiss.IndexFlatIP`，非近似）。
- **K**：主档 **K = 1000**；敏感性 **K = 100 / 3000**。
- **平局打散**：按 `(-sim, hash(seed, ts_code, date))` 排序，种子决定。
- **防前视断言（必须真能报警）**：
  1. 引擎断言：任一被使用邻居若 `idx(τ) + 6 > idx(t)` → `RuntimeError`；
  2. 引擎断言：任一图窗口若读到停牌缺行 → `RuntimeError`；
  3. 断言有效性检验：用「故意关掉库可用性约束」的对照运行必须**真的抛错**（产物 `assertion_violation.txt` 保存原文）。

## 5. 信号与组合（写死）

- **标签**：`r(j,τ) = open_qfq(j,τ+6) / open_qfq(j,τ+1) − 1`。用开盘到开盘，使「信号里的已实现收益」与
  「组合真正能拿到的收益」**同一条口径**（偏离 D5）。
- **信号**：`s(i,t) = (1/K) Σ_{(j,τ)∈N_K(i,t)} r(j,τ)`（论文式 (4)）。
- **横截面分组**：每个查询周在**当周可投资集合**内按 s 分 10 组（等频，`qcut` ties 取 `first` + 种子平局打散）。
- **主口径组合（多头）**：最高十分位，等权，多头持有 5 个交易日。
  **基准** = 同期当周可投资集合的等权收益。**H1 的收益 = 多头 − 基准**（A 股不可直接做空）。
- **对照列（不作判词依据）**：最高十分位 − 最低十分位（论文 Table 2/3 的 H–L 口径）。
- **调仓**：R5，周五收盘出信号，**次一交易日开盘成交**，持有 5 个交易日（至 t+6 开盘）。
- **可投资集合**（每周，信号日 t 判定）：PIT 在池 ∧ 上市 ≥250 交易日 ∧ 有图 ∧ t+1 有 `daily` 行 ∧ t+1 未涨停。

## 6. 成本与可成交性（写死）

- **主口径成本**：单边 **12 bp**（佣金 2.5 bp + 卖出印花税 5 bp 摊薄 + 冲击 4.5 bp），按 `|Δw|` 计。
  敏感性：**8 bp / 20 bp**。毛口径同时报告。
- **掩码（先于信号生效，且在成交日执行）**：
  - **不可买**：t+1 无 `daily` 行（停牌），或 `open(t+1) >= up_limit(t+1) − 0.001`（开盘即涨停，**用未复权价与 `stk_limit` 比**）；
  - **不可卖**：t+6 无 `daily` 行，或 `open(t+6) <= down_limit(t+6) + 0.001`；
  - 卖不掉时**顺延到其后第一个可成交开盘**，最长顺延 10 个交易日，超出则按最后可用收盘计值（并记 `forced_exit` 计数）。
- **换手**：`turnover_week = Σ|w_new − w_drift|`（双边），年化 = 周均 × 52。论文 Table 7 的「600%」即此口径。

## 7. 主检验量 + 阈值 + 判据（写死，不许临场改）

### H1（判词依据）
不微调 DINOv2-S、K=1000、PIT CSI300、A 股可执行口径（多头超额、单边 12 bp、掩码生效、种子 42/2024），
测试段 2021-01-04 ~ 2026-11-18 的**净 Sharpe**：

- **进**：净 Sharpe ≥ **0.5** 且 1000 次 block bootstrap 的 **95% CI 不含 0**；
- **退**：净 Sharpe ≤ **0** 或 CI 含 0；
- **部分复现**：0 < 净 Sharpe < 0.5 且 CI 不含 0。

Sharpe 定义：`SR = mean(r_net_w) / std(r_net_w, ddof=1) × √52`；`r_net_w` 为周度净超额收益，`rf = 0`。
bootstrap：**circular block bootstrap，块长 5 周，1000 次**，取 2.5 / 97.5 百分位。

### H2（机制检验，可否决 H1）
「只用本股自身历史」的库消融 vs 跨股检索：**方向必须与论文一致**（论文 Table 6 Panel A：Baseline 6.37 → Same-Stock 1.38）。
本单判据：`SR(baseline) − SR(same-stock) > 0`（用 H–L 口径比较，与论文同口径）。
符号反转 → 主结论标「机制未复现」，无论 H1 是否显著。

### H3（可交易性）
成本 8 bp → 20 bp 的净 Sharpe 衰减幅度；若 20 bp 下转负，判词必须写明「成本敏感，A 股印花税与冲击成本会吃掉信号」。

### H4（微调增益，仅阶段 B）
`SR(FT-DINO) − SR(DINOv2) > 0` 才算复现论文 Table 3 的方向；**没跑就写「未跑」，不得用未跑的结果说事**。

### 种子纪律
同一判词必须换 **2 个独立种子（42 / 2024）** 各跑一次，只报 `mean ± range`。
种子间**符号不一致即判「未复现」**。阶段 A 的种子作用于：渲染 y 轴 padding（§3.1）、邻居平局打散、bootstrap。
**披露**：阶段 A 除这三处外完全确定，故种子间差异预期极小；「符号一致性」检验在阶段 A 是弱检验，本单如实说明，
不据此夸大成「稳健性通过」。

### 失败即作废的条件
结果不能由「代码提交 + 快照 manifest」复现；关键数据缺失；断言未真正生效；独立复算与建模侧相对差 > 1e-6 且未以复算值为准。

## 10. 阶段 B 的超参（论文只给符号，全部在此写死）

| 项 | 取值 | 依据 |
|---|---|---|
| 损失 | `L = (1/B) Σ_a D_KL(p_a ‖ q_a)`（论文式 (8)）；`p_ab ∝ exp(−|u_a−u_b|/κ_r)`，`q_ab ∝ exp(s_ab/κ_z)` | 论文式 (6)(7) |
| 温度 | `κ_r = 0.05`，`κ_z = 0.10` | 论文只给符号；取使 `p` 在 rank 差 0.05 处衰减到 1/e 的量级 |
| 优化器 | AdamW，`lr = 3e-5`，`wd = 0.01`，`betas=(0.9,0.999)`，grad clip 1.0 | 全参数微调的小学习率常规档 |
| 调度 | 5% 线性 warmup + cosine 衰减到 0 | 论文 A.2 原文「linear warmup followed by cosine decay」 |
| 轮数 | **1 个完整 pass**（1 epoch，≈ 603 步 @ batch 128） | 论文 A.2「one complete pass through the training sample」 |
| batch 构造 | 128 张 = **4 个日期 × 32 只**，日期在训练段内按种子抽样 | 论文「batches contain stocks from multiple dates」 |
| 标签 rank | `u = PctRank_t(r5)`，在**原始日期**的全池横截面内计算（不随 batch 变） | 论文 A.2 原文 |
| 检查点 | 每 10% 步存一次（10 个），用**固定抽样 2,000 张验证图**算 val KL，取最小者 | 论文「checkpoint selected using KL loss on the complete 2000 validation sample」的 CPU 缩放版 |
