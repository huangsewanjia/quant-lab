## 目录内容

| 文件 | 是什么 |
|---|---|
| `source_article.md` | 界面新闻（穆玥）2026-11-12《私募量化指增策略风光不再……》正文，**逐字照抄**转载镜像 `.md` 版，未改写 |

## 两个脚本怎么跑

```powershell
# ARM A：输出写到仓库外（本轮原样保留，未改写）
python probe_armA_no_registry.py
# ARM B：同上
python probe_armB_registry_guided.py
```

> 两个脚本里**保留了本轮实跑时的绝对路径**（用于把 JSON 结果写到本工作目录外），因此不是开箱即跑的。逻辑部分与本轮实跑**逐字一致**，改动路径即可复跑。

## 关键实测结论

| 指标 | 前（ARM A） | 后（ARM B） |
|---|---|---|
| 取数探测 HTTP 请求 | 6（其中 **4 次注定失败**） | **5（0 次已知失败源）** |
| 取数探测耗时 | 2.50 s | **2.05 s** |
| 口径裁定组合试算 | **42** | **7** |

对照 WORK-404 原单的取数探测**重建基线 ≈51 次请求**（含 12×45 s 东财空跑），本实验实测 **5 次**。

## 本实验的已知缺口

- **S2 的判定表未过 `audit/audit_recompute.py` 独立复算**。该脚本的复算项是 WORK-404 口径（16 个数字写死在脚本里），不适用于本实验。已在 `experiments/registry.md` 显式标注，**不当作「已验收」**。
- 证据强度：单篇、单会话、单网络条件，**样本量 = 1**。ARM A 是**路线复现不是盲测**，「前」是真实成本的下界。
