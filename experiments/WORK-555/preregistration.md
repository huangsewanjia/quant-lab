## 0. 一句话核心假设（可证伪）

> 在同一份自建 A 股 CSI300 日频面板、同一时间切分、同一组随机种子下，**六型异质集成 DEE 的样本外 RankIC 高于最佳单族集成（MLP-only）**，即 `Δ_ic > 0`；`Δ_ic` 定义见 §6。

- 评价指标：测试段日频截面 RankIC（Spearman）为主检验量；IC（Pearson）、组合年化 / Sharpe / MDD / 换手为次要指标。
- 数据截止点：**2021-01-29**（仅用于给测试段最后一日 2020-12-31 算次日收益标签；不使用其后任何数据）。
- 基准：无基准超额要求（绝对水平不作 KPI，见 §6.3）。
- 什么结果会推翻假设：`Δ_ic ≤ 0`（§6.2 退档）；或净 Sharpe < 0（§6.2 直接退）。
- 停止条件：§7。

## 2. 股票池（冻结）

- **成分来源**：`quantdb.duckdb` 表 `index_weight`，`index_code = '000300.SH'`，共 250 个快照日（月末），每个快照恰好 300 只（249 个快照 300 行、1 个快照 298 行，均为源数据事实，照实使用）。
- **point-in-time 口径**：交易日 t 的成分 = **快照日 ≤ t 的最新一个月末快照**。月末快照本身在月末当日生效，故 t=月末当日用当月新名单，t=月末与下一月末之间用旧名单。
  - **前视检查**：任何 t 日的成分只来自 ≤ t 的信息，**不含未来名单**；成分调整滞后上限 1 个月（保守方向，不会引入前视）。
  - 与论文口径的**一致**：论文 Table 1/2/3 的 "CSI 300 constituent universe"，同为 CSI300、同为日频。
  - 与论文口径的**偏离**：论文正文未说明是否使用 point-in-time 成分（环 1 WORK-527 存疑点 3），本单**明确使用 PIT 口径**，属本单比论文更严格的方向。
- **上市满 N 个交易日过滤**：N = **60**（自 `list_date` 起计交易日）。不满足的股票当日不可入选池（覆盖 §5「上市首日排除」的仓库规则）。
- **退市**：退市股票**保留到最后交易日**，自次一交易日起自然无行情行、不进入可交易集合；**不回溯剔除**（避免幸存者偏差）。
- **停牌**：停牌日**保留行**，价格前向填充到上一收盘、成交量置 0（仓库 §5 规则）；停牌日**不可成交**，且标签（次日收益）在停牌日无效 → 该行不进训练样本、不进 IC 统计、不进组合。
- **涨跌停**：停牌/涨跌停价只用于回测可成交判定，**不进模型特征**。

## 3. 因子集（冻结）

### 3.1 与论文口径的关系（偏离单列）

- 论文使用 **qlib 官方 Alpha158（158 列价量因子）**。
- 本单**不复刻 qlib 表达式引擎与全部 158 列**，改为**自实现 Alpha158 风格算子子集：48 列**，逐条公式见附录 A。
- 偏离原因：qlib 官方 CSI300 二进制数据集本机可达性未验证（环 1 未下载、未实测），自建 panel 与 qlib 数据集口径（复权基准日、成分口径）不一致，强行混用会引入无法归因的口径污染。
- 偏离方向：**因子维度减少**（48 vs 158）→ 预期压低绝对水平；论文的主检验量是**相对量** `Δ_ic`，绝对水平不作 KPI（§6.3）。

### 3.2 字段与口径

- 价格字段：`v_daily_hfq`（后复权），仓库规则「复权一律用视图，不要自己算」（字段字典 §2）。
- 成交量 `vol`（单位：手）、成交额 `amount`（单位：千元）取自 `daily` 原表，**不做除权调整**（字段字典 §2）。
- **不使用 vwap 类字段**：避免 WORK-498 记录的「未乘复权因子导致 IC 从 0.042 掉到 0.003」问题；附录 A 中所有价量组合项均在 **hfq 价格空间**内自洽构造。
- **基本面字段一律不用** → **不涉及 `ann_date` 时点问题**（无财报因子 = 无公告日泄漏面）。这是本单对工单「`ann_date` 时点规则的字段如何处理」的明确回答：**本单因子集不含任何基本面字段**。
- 因子最大回看 60 个交易日。

### 3.3 截面预处理（冻结，复用仓库既有口径）

1. **MAD 5× 去极值**：截断到 `median ± 5 × 1.4826 × MAD`；MAD = 0 时退化为按分位数截断；
2. **截面 z-score**：`x ← (x − mean) / std`（std = 0 时该因子当日置 0）；
3. 每日每因子独立处理；处理在**当日全池截面**上做（池 = 当日 PIT 成分 ∩ 有行情 ∩ 非停牌）。
4. 说明：qlib 官方 `cs_zscore` 为纯 z-score（不去极值），本单沿用 **WORK-449 v1.0 已冻结的 MAD 5× + z-score** 口径（仓库既有约定，不另起一套）。

### 3.4 标签（冻结）

- `y_{i,t} = close_hfq(t+1) / close_hfq(t) − 1`（**原始次日收益，不做截面标准化**；IC 对仿射变换不变，故不影响相关系数指标）。
- 标签有效性：t 与 t+1 两天都必须有**真实成交行**（非停牌）；否则该行无标签。
- 样本行剔除规则（冻结）：任一 48 个因子为 NaN、或标签无效、或当日不在 PIT 池内 → **整行剔除**，不插值、不前向填充补因子。

## 4. 专家构造（冻结）

### 4.1 与论文一致的部分（逐字照抄 §6.1）

| 项 | 取值 |
|---|---|
| 专家数 N | 论文 50；**本单 20**（见 §8 偏离 D1） |
| 类型配比 | 论文 10 linear / 2 ridge / 5 lasso / 3 elasticnet / 15 MLP(hidden 32) / 15 soft tree(depth 12) |
| 本单配比（N=20） | 4 linear / 1 ridge / 2 lasso / 1 elasticnet / 6 MLP(32) / 6 soft tree(12) |
| bootstrap 池比例 β | **0.8789** |
| 特征子集比例 γ | **0.5**（且满足全覆盖约束） |
| 惩罚线性变体强度 α | **1e-3**（ridge / lasso / elasticnet） |
| 优化器 | **Adam**，lr **1e-3**，weight decay **1e-4**，batch size **8192**，MSE loss |
| 早停 | patience **50** 步，每 **20** 步评估一次，**监控集成级验证损失**（不是单专家损失） |
| IC 过滤容差 κ | **1.5** |
| dropout | 无 |
| soft tree 深度 | **12** |
| MLP 隐层宽度 | **32** |

### 4.2 三重随机化（论文 §2.3，本单逐条落地）

1. **bootstrap 抽样**：专家 k 从训练行池中有放回抽取 `⌊β × T_train⌋` 行作为自己的训练池 `B_k`（T_train = 训练段可用样本行数）。
2. **特征子集**：`F_k` = 从 48 个因子中随机取 `⌊γ × 48⌋ = 24` 个，**并施加全覆盖约束**：全部 48 个因子必须至少被一个专家使用。落地方式：逐专家抽取后检查覆盖，若有因子未被覆盖，则用该因子替换该专家子集中**随机抽中的一个**已选因子（替换对象由该专家的 seed 决定）；此修复在分配阶段一次性完成，并写入日志（记录被修复的专家与因子）。
3. **类型分配（round-robin 循环）**：论文 §2.3 为「round-robin cycling over the six types」，但未给出与配比并存的精确顺序。本单**冻结为平滑加权轮转（SWRR）**：`credit_i` 初始为 0，每步对每个类型 `credit_i += q_i`，取 credit 最大者（并列时按 linear→ridge→lasso→elasticnet→MLP→soft tree 固定序）入选该步，`credit_i -= N`。
   - **本单 N=20 的冻结类型序列（附录 B 逐位列出）**：
     `mlp, tree, linear, lasso, mlp, tree, linear, ridge, mlp, tree, elasticnet, mlp, tree, linear, lasso, mlp, tree, linear, mlp, tree`
   - 同法在论文 N=50 下得到 `mlp, tree, linear, lasso, mlp, tree, elasticnet, linear, …`（附录 B 完整列出，供对照）。

### 4.3 同步训练循环（论文 Algorithm 1，冻结）

- 第 `step` 步：每个专家 k 用**自己的 bootstrap 池** `B_k` 抽一个 mini-batch（8192 行），在自己的特征子集 `F_k` 上计算 `L_k = MSE + L_reg^(k)`，做**一次**梯度更新。
- 每 20 步：用固定验证子样本（从验证段抽样 **20,000 行**，抽样种子 = 该臂的 seed，一次抽好、全程固定）计算**集成级**验证 MSE；连续 50 步无改善 → 全局早停（所有专家同时停），恢复验证损失最优的那一步的参数快照。
- 惩罚变体的处理（论文 §2.2）：ridge/lasso/elasticnet 把正则**直接写进目标函数**并**关闭优化器 weight decay**（防止双重惩罚）；linear / MLP / soft tree 的 weight decay = 1e-4。
- 随机种子：**42、43**（两轮均跑，报告 mean ± range）。每个 seed 派生全部子随机源（bootstrap 抽样、特征子集、mini-batch 顺序、初始化、验证子样本抽样），派生规则写入代码（`numpy.random.SeedSequence` 固定 spawn 键），保证可复现。

### 4.4 聚合与质量控制（论文 §2.4 / Eq.(1)，冻结）

- 验证段逐专家计算日频截面 **RankIC**，取测试期外的验证段均值 `IC_k`。
- 保留集合 `A = {k : IC_k ≥ mean(IC) − κ × σ_IC}`，κ = 1.5，σ 为验证段 RankIC 的**总体标准差**（ddof = 0）。
- 最终信号 `ŷ_ens = mean over k∈A of f_k(x_{F_k})`（**原始预测等权平均**，不做事后标准化，与论文 Eq.(1) 一致）。
- 退化保护（冻结）：若 `A` 为空，则 `A := {全部专家}` 并在日志记 `degenerate_filter_fallback=true`；若 `|A| = 1`，该专家即为集成信号，同样记日志。

### 4.5 专家族内部结构（冻结）

- **linear / ridge / lasso / elasticnet**：单隐层退化为仿射模型 `ŷ = w·x + b`；ridge 正则 `α‖w‖²`，lasso `α‖w‖₁`，elasticnet `α(λ₁‖w‖₁ + λ₂‖w‖²)`（l1_ratio = 0.5）。**含偏置项不参与惩罚**。
- **MLP**：1 个隐层、宽度 32、**带 batch normalization**（论文 §2.2 明写 "with batch normalization"）、激活 ReLU、输出线性、**不使用 dropout**（论文 §6.1 明写 no dropout）。
- **soft tree**：深度 12 的二叉软决策树。内部节点 n 的路由门 `g_n(x) = σ(a_n·(x_j − t_n) + b_n)`（论文 §2.2 的 `σ(a_nᵀx + b_n)` 在单特征门上的特例），叶子值 `μ_ℓ` 可学习，输出 `ŷ = Σ_ℓ P(ℓ|x)·μ_ℓ`（路径概率加权）。树结构由 CART（`max_depth=12`）在**该专家自己的 bootstrap 池**上预生长，冻结为阈值 t 与特征 j，软化参数 `a_n, b_n` 与叶子值 `μ_ℓ` 由 Adam 联合训练。

### 4.6 三档对照臂（冻结）

| 臂 | 说明 | 论文对应 |
|---|---|---|
| A `DEE` | 六型混合 N=20，三重随机化 + IC 过滤 + 等权聚合 | Table 1 DEE / Table 2 Full DEE |
| B `MLP-only` | **同 N=20、同样 bootstrap/特征子集/IC 过滤/等权聚合**，但 20 个专家**全部为 MLP** | Table 2 "MLP only" |
| C `XGBoost` | 单一 XGBoost 模型，全特征、全训练行 | Table 1 XGBoost |

- 臂 B 是 **「最佳单族」的指定参照**（论文 Table 2 中 MLP-only RankIC 0.055 高于 tree-only 0.054、linear-only 0.051）。
- 臂 C 超参（冻结，采用 qlib `Alpha158` 任务默认值）：`n_estimators=2000, learning_rate=0.05, max_depth=6, subsample=0.8, colsample_bylevel=0.8, colsample_bytree=0.8, reg_lambda=1, objective=reg:squarederror, eval_metric=mse, early_stopping_rounds=50`。

## 5. 成本与组合（冻结）

- **组合**：top-50 等权，**日频调仓**（论文 Table 3：top-50 equal-weight, daily rebalancing）。
- **信号时点**：t 日收盘后用 t 日因子打分 → 持仓赚取 t → t+1 的收益（标签口径一致）。
- **可成交规则**（贯穿全链路，引擎内置断言）：
  1. **买入受限**：t 日停牌、t 日收盘价 ≥ `up_limit`（涨停）→ 该股当日不可买入；
  2. **卖出受限**：t 日停牌、t 日收盘价 ≤ `down_limit`（跌停）→ 该股当日不可卖出，**强制持有**（权重保留到下一可交易日），不假设能卖出；
  3. 涨停判定用 `stk_limit` 表的 `up_limit`/`down_limit`（主源，2007-01-04 起覆盖全窗口）；`stk_limit` 缺失当日按**不可买入、不可卖出**处理（保守），并记日志；
  4. 停牌判定用 `suspend_d` 表当日是否有该股记录；
  5. **断言**：任何读取「不可成交价」的路径（组合构建、收益结算）必须抛错中止，错误信息含 `ts_code / trade_date / 违规类型`；`stk_limit` 缺失导致的「保守视为不可成交」是显式豁免，不触发断言。
- **成本**（单边费率，扣在成交名义上）：

| 档位 | 单边佣金+冲击成本 | 卖出印花税 | 用途 |
|---|---|---|---|
| 主口径 | **8 bps** | **10 bps** | 主结论 |
| 敏感性 | **5 bps** | **10 bps** | 敏感性分析 |

  - 印花税 10 bps（0.1%）为 2017-01-01 ~ 2020-12-31 期间 A 股卖出侧实际税率（2023-08-28 起才降至 5 bps），适用于本单全部测试期；
  - 成本算法：`cost_t = buys_t × c + sells_t × c + sells_t × stamp`，其中 `buys_t = Σ max(Δw,0)`、`sells_t = Σ max(−Δw,0)`、`Δw` 为 t 日目标权重与 t−1 日实际持仓权重之差；
  - 净收益：`r_net,t = r_gross,t − cost_t`。
- **换手口径**：报告 `双边换手 = buys_t + sells_t`（日均与累计），与成本口径同源。
- **组合收益口径**：等权持仓收益 = Σ w_i × r_i（t→t+1），组合层面按日累加成净值曲线。
- **年化口径**（复用仓库字段字典 §3）：年化收益用自然日折算 `(1+R)^(365.25/自然日数) − 1`；波动用交易日折算 `std(日净收益) × √252`；两者不混用。
- **Sharpe**：主口径 **rf = 0**（论文未给 rf，Table 3 的 1.846 按 rf=0 理解）；同时给出 rf = 1.5%（仓库既有口径）的对照列。**进/退判词用 rf=0 的净 Sharpe**。
- **MDD**：按日频净净值曲线计算最大回撤（负值表示）。
- **强制持有的记账**：因跌停/停牌被强制持有的股票，其权重在下一可交易日重新分配时通过目标权重与实际权重之差自动体现卖出成本，不额外惩罚。

## 6. 主检验量与阈值（冻结）

### 6.1 主检验量

```
Δ_ic = ( RankIC_DEE − RankIC_最佳单族 ) / RankIC_最佳单族
```
- `RankIC_DEE` = 臂 A（DEE）在**测试段日频截面 RankIC 的时间均值**；
- `RankIC_最佳单族` = 臂 B（MLP-only，同 N=20、同样随机化与聚合）同口径时间均值；
- 两臂用**同一份面板、同一时间切分、同一种子集合**（seed 42 与 43 各跑一次 → 先按种子逐一算 Δ_ic，再对两种子取 mean，并同时报 range）。

### 6.2 判定规则（逐条可判，照抄工单）

| 判据 | 结论 |
|---|---|
| `Δ_ic ∈ [+2%, +30%]` | **进带**（方向复现即算通过；绝对水平不设 KPI） |
| `Δ_ic ≤ 0` | **退**（DEE 不优于最佳单族） |
| `Δ_ic > +50%` | **退**（单族基线本身跑坏、不可比） |
| 净 Sharpe < 0（rf=0，主口径 8 bps） | **直接退**（净额口径含成本） |
| 两种子 `max − min > 0.01`（RankIC 绝对量） | **不稳定**：不改变进/退档位，但**必须在结论中明说** |
| 95% CI 含 0 | 写明「**未复现**」，仍算交付 |

- 两种子样本量下，CI 用**正态近似 t 分布**（自由度 = 种子数 − 1 = 1）给出，标注为「2 种子，区间极宽，仅作参考」。
- 「最佳单族」若因臂 B 明显跑坏（`RankIC_MLP ≤ 0`）而使 `Δ_ic` 失去意义，则 `Δ_ic` 判**不可比**，按「退」处理并在结论中写明卡点。

### 6.3 绝对水平不作 KPI

不追论文 Table 3 的年化 38.56% / Sharpe 1.846 / MDD 17.15%（专有面板、无成本、无 PIT 口径、口径不可得）。本单只检验 §6.1 的**相对量**。

## 7. 失败判据（冻结）

1. **不可复现**：同一 commit + 同一数据快照 + 同一命令重跑，核心指标相对差 > 1e-6 → 结果作废，先查快照漂移与随机源。
2. **独立复算不一致**：审计脚本（不复用建模函数）复算的 RankIC / IC / Sharpe / 年化 / MDD / 换手与建模侧相对差 > 1e-6 → 以**复算值为准**，回退到对应阶段重做。
3. **前视 / 幸存者 / 退市偏差**：发现成分前视、退市回溯剔除、停牌行删除、标签跨停牌 → 结果作废。
4. **掩码断言未生效**：刻意关闭可成交掩码时断言不触发 → 视为断言形同虚设，交付不成立。
5. **数据缺口**：端点 40203/403 且库内无替代列 → 停下回报缺哪个端点、缺多少历史，不降级猜数。
6. **协议变更**：预注册落盘后想改口径 → 停下回报，不在结果里静默改。
