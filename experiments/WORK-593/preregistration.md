## 1. 三套锚定表示的构造式（逐条可执行）

### 1.1 原始字段与基础层

来自 `daily` / `adj_factor` 两张表（单位按 `data_contracts/field_dictionary.md`）：

| 符号 | 含义 | 单位 |
|---|---|---|
| `c,o,h,l` | 不复权开高低收 | 元/股 |
| `vol` | 成交量 | 手（1 手 = 100 股） |
| `amount` | 成交额 | 千元 |
| `f_t` | 复权因子（Tushare `adj_factor`，纯乘法） | 无量纲 |

**自建 vwap（原始口径）**：

```
vwap_raw_t = amount_t × 10 / vol_t        # 千元×10/手 = 元/股，单位换算见 §3
```

**基础层（后复权等价，只在内存中作为三套表示的公共被乘项，不单独出快照）**：

```
P_t = c_t · f_t ,  W_t = vwap_raw_t · f_t ,  V_t = vol_t / f_t
```

方向由「`W_t · V_t = vwap_raw_t · vol_t` 不变」锁定：价格乘因子，成交量**除以**因子
（论文 §VI-A「We multiplied VWAP by the price factor, divided volume by it」）。

### 1.2 三套锚定（每只股票 i 一个标量 `f_i^(A)`）

| 表示 | 代号 | 锚点 `T_A` | `f_i^(A)` 取法 |
|---|---|---|---|
| **端锚定** | `E` | 快照最后一天 2026-11-13 | 股票 i 在 `trade_date ≤ 2026-11-13` 的**最后一个有 `adj_factor` 的交易日**的 `f` |
| **截止锚定** | `C` | 切点 2020-12-31 | 股票 i 在 `trade_date ≤ 2020-12-31` 的最后一个有 `adj_factor` 的交易日 的 `f`；若该股 2020-12-31 前无任何 `f`（2021 年后上市），取该股窗口内**首个** `f` 并在 manifest 标记 `fallback_first=true` |
| **既往锚定** | `P` | 该股窗口内首个交易日 | 股票 i 在 `trade_date ≥ 2010-01-04` 的**第一个有 `adj_factor` 的交易日**的 `f` |

**统一变换式**（对 `A ∈ {E, C, P}`，逐股逐日）：

```
p_t^(A) = c_t · f_t / f_i^(A)          价格（open/high/low/close 同式）
w_t^(A) = vwap_raw_t · f_t / f_i^(A)   vwap
v_t^(A) = vol_t · f_i^(A) / f_t        成交量（手）
k_i^(A) = 1 / f_i^(A)                  该股在表示 A 下的乘性尺度
```

三套表示**只允许**由上式产生：同一份基础层、同一批行、同一批缺失日，差异**只能**来自
`f_i^(A)`。取数只做一次（`scripts/work593_fetch.py`），表示派生走
`scripts/work593_represent.py`，派生文件各自记 sha256。

**为什么这三套**：`E` 是「今天回过头去复权」的口径（未来信息进入表示）；`C` 是论文的
真实锚定（`c_i = A_{T_c,i}/A_{T_end,i}`，§VII-A）；`P` 是论文的 past-anchored 提供者
（arm AH，逐股按起始日锚定，去掉对未来的依赖）。`E − C` 是本单主检验量。

### 1.3 单位与不可变量声明

- 价格、vwap：元/股；成交量：手；三者均**已乘/除复权因子**，即论文意义的 adjusted 字段。
- 换手/成交额恒等式 `w_t^(A)·v_t^(A) = vwap_raw_t · vol_t` 在任意 `A` 下成立（§2 C2）。
- 「表示的差异」对**比值型因子**在单只股票内可约掉（`p_t/p_s` 不含 `f_i^(A)`），
  但**跨股票**不可约（每只股票有自己的 `k_i^(A)`）——这正是价格水平型因子失稳、
  排名型因子失稳的来源。论文 §VII-A 与此一致。

## 6. 主检验量与判定阈值（数字抄死）

**单因子 IC**：对每个评估日 `t`，在该日有效横截面上算 `values_f(t)` 与 `ret20(t)` 的
**Spearman 秩相关**（`IC_f(t)`）；`IC_f = mean_t IC_f(t)`，`ICIR_f = mean_t/std_t`。
三套表示各算一遍（标签在秘密意义下与表示无关：`ret20` 是同一只股票两个调整价的比，
`f_i^(A)` 全部约掉，逐值一致；本单**断言**三套表示下 `ret20` 逐值相等，最大绝对差 = 0）。

**主检验量**：

```
ΔIC_f  = IC_f(E) − IC_f(C)
ΔIC_pool = (1/36) Σ_f ΔIC_f
IC_pool(C) = (1/36) Σ_f IC_f(C)
占比 R = ΔIC_pool / IC_pool(C)
```

**统计推断**：评估日序列 `d_t = (1/36) Σ_f [IC_f,E(t) − IC_f,C(t)]`；
**循环块 bootstrap**，块长 **20**（对应 20 日重叠标签），重采样 **1000** 次，95% 分位区间。
种子 **42 / 43 / 44**，**三个种子各跑一遍并分别报告**。

**判定（合取，全部满足才判「复现成立」）**：

1. `ΔIC_pool > 0`；
2. 三个种子的 95% CI **都不含 0**；
3. `R ∈ [0.10, 0.18]`（论文 §VII-A：已发表方法「about 14% of their IC」，本单把 10–18% 写死为区间）；
4. 三个种子的 `ΔIC_pool` 符号一致（本判据已由 1–3 隐含，仍单列，防实现漂移）。

任一条不满足 → 判词写「**未复现**」，并写清哪一条不过、实测值多少。
判定阈值**不得**在看到结果后放宽或收窄；也不得为了过第 3 条去改因子池组成。

**次要口径（报告但**不**参与判词）**：

- 子组均值：A 组 11 条 / B 组 25 条分别的 `ΔIC` 与 `R`；
- 自适应组合器（§7）的池级 IC 在 E / C 两套表示下的差；
- 论文 Table V 式「因子级 `ΔIC_f` 分布」：`|ΔIC_f| > 0.005` 的因子占比。
