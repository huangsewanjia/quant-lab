### D3 · 成分生效区间被塌缩成 min..max（实现缺陷，由独立复算发现）

| 项 | 内容 |
|---|---|
| 现象 | 首轮独立复算（`audit/recompute_work593.py`）与建模侧逐因子 IC 比对：36 条里 **12 项超 1e-6**（blocking），连**不含任何滚动窗口**的 `PL01`（裸收盘价）都对不上：建模 −0.046371 vs 复算 −0.044180（相对差 3.6%） |
| 根因 | `scripts/work593_fetch.py` 首版把每只股票在一段时间内出现过的**多个互不相连的成分区间**先 `min(start)..max(end)` 塌缩、再合并，得到一条横跨空档的假区间 |
| 量化 | 掩码股票-日：塌缩版 3,590,266 vs 逐快照展开版 3,260,000，**虚增 10.1%** |
| 修复 | 改为「逐快照展开 → 只在区间相邻/重叠时合并」，spells 1,862 → 2,505；`snapshot_manifest.json` 增列 `mask_stock_days` 便于复核 |
| 影响 | 首轮的 IC / ΔIC / 占比 / bootstrap 全部作废并重跑（本文件对应的所有数字均来自修复后版本）；修复前后的数字只在本条留痕，不进入报告 |
| 附带修复 | 复算脚本的 `roll_max/roll_min` 未按 `min_periods = max(5, n//2)` 截断窗口，与协议不一致 → 已对齐（影响 PL10/INV14/INV16/INV17） |

**教训**：`min..max` 合并「看起来等价」，但它把「中途被调出又调回」的股票当成连续成分，会同时虚增股票池与 IC 的有效横截面。这类错误不会让程序报错，只会让所有数字偏移几个百分点——只有独立复算（不同实现路径 + 不同数据入口）才抓得住。

### D4 · 复算脚本自身两处实现错误（由「复算 vs 建模」对不上而暴露）

掩码修好（D3）后仍有 5 条因子对不上，逐个定位为**复算脚本自己的错**，不是建模侧的错：

| # | 位置 | 错误 | 实测差异（建模 − 复算） | 修复 |
|---|---|---|---|---|
| 1 | `roll_std` | 用 `Σ(x_t − m_t)²` 的滑动和算方差。每期窗口均值 `m_t` 不同，这个和在数学上不是任何一期的方差 | `PL09`（`STD(C,20)`）IC −0.0495 vs −0.0468（5.4%）；`INV13` 8.9%；`INV20/INV21` 经 `roll_corr` 内部同样偏移 | 改为 `var = (Σx² − c·m²)/(c−ddof)` |
| 2 | `ts_rank_last` | 数的是「窗口里有多少值**不小于**当前值」，方向反了（协议/QLib 口径是「有多少**不超过**当前值」） | `INV25` IC −0.00376 vs +0.00843（连符号都不同） | 改为 `Σ 1{w ≤ w_last}/n` |

**处置**：两处修好后重跑复算；同时把比对判据补上零安全分支
（`|a−b| ≤ 1e-6·max(|a|,|b|)` **或** `|a−b| ≤ 1e-9`），因为 `INV` 组 ΔIC 本身就在 1e-8 量级，
纯相对差会把「数值零 + 浮点噪声」判成 100% 不一致（WORK-449 踩过同一个坑）。

**教训**：独立复算的价值不只是查建模，也查自己。这次两条错都属于「看起来对的常见写法」，
只有拿两套实现逐值对，才会露馅。

### D5 · 5 日窗口的 `min_periods` 实现不一致（协议漏洞，由独立复算发现）

| 项 | 内容 |
|---|---|
| 现象 | 掩码（D3）与两处写法（D4）修好后，仍剩 `INV16/INV17`（`MAX(H,5)/C−1`、`MIN(L,5)/C−1`）对不上：IC ≈ 0.037574（建模）vs 0.037747（复算），差 1.7e-4 |
| 根因 | 预注册 §5 只写「`MAX(H,5)`」，**没写 min_periods**；建模侧对 20 日窗口统一用 `max(5, n//2)=10`，却对 5 日窗口硬写了 `min_periods=3`，与自己声明的通用规则（`max(5, n//2)`）不一致。停牌日会让矩阵出现 NaN，因此 min_periods 在整段历史上都起作用，不只是预热期 |
| 处置 | 统一为「窗口长度 n 需要 n 个有效值」（`min_periods = max(5, n//2)`，5 日窗口即 5）；建模侧重跑，复算脚本本来就是该口径。协议 v1.1 §偏离表补记 |
| 影响 | INV16/INV17 的 IC 变动 ~0.5%，池级 ΔIC 变动 < 1%；判词不变 |
