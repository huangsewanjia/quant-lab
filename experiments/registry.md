### 填表规则

| 规则 | 内容 |
|---|---|
| 一行一实验 | 一个实验 = 一个实验 ID。同一实验的多个口径不分行，写进「关键参数」。 |
| 失败留痕 | 「失败 / 被证伪项」**不得留空**。确实没有就写「无」。 |
| 数字只抄审计产出 | 「主要结果」里的数字必须能在 `experiments/<EXP>/audit_findings.json` 或 `experiments/<EXP>/metrics.json` 中找到对应。 |
| 口径引用不复制 | 参数里写「rf=1.5%」这类值要同时在 `metric_definitions.md` 有定义；**不在本文件另立定义**。 |
| 未取到写明 | 数据没取到就写「未取到」+ 原因，不用代理指标冒充原始字段。 |

**⚠ 稳健性警告（与上一行判词同等重要，务必一起读）。** 换 seed（43）、用**同一套协议、同一份数据、同一批因子**重跑三臂后，ΔSharpe = **−0.551457**（95% CI [−1.0867, −0.1381]，区间不含 0），按 §9.4 的机械规则会得到**相反的判词「复现成立（进）」**；两轮的 ΔSharpe 量级几乎相同（0.5516 vs 0.5515）而**符号相反**，且两轮 CI 都不含 0。⇒ **本实验在可实现 Sharpe 轴上功效不足：主检验量的符号不由数据决定，而由训练随机种子决定**。能站住的结论只有两条：① 协议冻结轮次（seed 42）的判词是「未复现（退）」；② **表观 IC 轴的方向在两个 seed 下同为负**（−0.004418 / −0.002063），「去掉掩码并没有让表观 IC 上升」这一条**对种子稳健**。根因：AdjMSE 权重由 `sign(pred)·sign(target) > 0` 决定，预测在 0 附近符号不连续，而本单模型预测离散度只有标签的 0.58%。详见 `failure_log.md` §3.19b、报告 §11.3 与表 10。
