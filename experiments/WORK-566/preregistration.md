## 7. 组合、成本与 A 股约束（写死）

### 7.1 组合构造（论文附录 G，逐条照搬）

| 项 | 规定 |
|---|---|
| 选股 | 每个预测日 t 取预测分最高的 **K=30** 只，等权（`w_i = 1/30`），**纯多头 long-only**（CN_ALL 口径） |
| 入选门槛 | 当日可选标的 ≥ 30 只；不足 30 只的日期**整日跳过**（不建仓） |
| 成交 | 预测基于 t 日收盘信息，**t+1 开盘买入**；该批次持有固定份额至 **t+21 日收盘卖出** |
| 价格 | 使用**复权后的开收盘价**（hfq），与论文「consistently adjusted open and close prices」一致 |
| 重叠批次 | 所有重叠批次**共享同一个现金与净值账户**，初始单位现金 V₀=1；批次不按初始权重再平衡 |
| 批次预算 | `B_t = min(V_t / H, max(C_t, 0) / (1 + c))`，H=21；CN 口径预算覆盖买入额与入场成本，不借款 |
| 持仓份额 | `q_i = B_t · w_i / P^open_{i,t+1}`（复权价格坐标下的分数份额） |
| 成本 | 每单位成交名义金额 **c = 0.0005（单边 5bps）**，**买入与卖出都收**（含最终清算）；不同批次的反向成交**不轧差** |
| 换手 | `TO_d = A_d / (2·V_{d-1})`，`A_d` = 当日全部成交名义金额绝对值之和；报告 `mean(TO_d)` |
| 现金与净值 | `C_d = C_{d-1} − Σ Δq·P − F_d`；`V_d = C_d + Σ Q_{i,d}·P^close_{i,d}`；`R^net_d = V_d/V_{d-1} − 1` |
| 终止条件 | 若任一开盘/收盘/交易后估值的 NAV ≤ 0 → 终止并报告为**账户失败**（本单不得发生；发生了即为失败判据） |

### 7.2 年化与回撤（论文 Eq.42/43，照搬）

| 指标 | 定义 |
|---|---|
| Net AR | `252 × mean(R^net)`（**算术年化，不是 CAGR**） |
| Net SR | `sqrt(252) × mean(R^net) / sd(R^net)`，无风险利率取 0，`sd` 为样本标准差 |
| MDD | `min_d (V_d / max_{u≤d} V_u − 1)`，含 V₀=1，基于日收盘净值序列 |
| IC / RankIC | 每个预测日截面 Pearson / Spearman 相关；**有效日等权平均 ×100**；有效日要求：有效配对 ≥3 且预测与实现均非常数；并列取平均秩 |

> 仓库既有口径（`data_contracts/metric_definitions.md`）的年化是**自然日 CAGR**，
> 与本单论文口径**不同**；本单在组合指标上一律用**论文口径（252 算术年化）**，
> 并在报告中单列标注口径来源（`metric_definitions.md` 与论文**不可混用**）。

## 8. 算力降级路径（写死）

论文环境：8×RTX 5090。本机：**无 GPU（`nvidia-smi` 不存在）、8 vCPU、约 4 GB 可用内存、
torch 2.15.0+cpu（CPU-only）**。

| 论文配置（附录 C/D） | 本单配置 | 理由 |
|---|---|---|
| d_model = 128 | **64** | CPU 训练预算 |
| Transformer 层数 4 | **2** | 同上 |
| 注意力头 8 | **4** | 与 d_model 保持比例 |
| FFN 512 | **128** | 同上 |
| d_z（潜空间）128 | **64** | 与 d_model 一致；读出输入维由 312 变为 **184**（40+16+64+64） |
| batch 256、4 epoch、≤1000 update/epoch | **同（batch 256，4 epoch，≤1000 update/epoch ≈ 1.02M 样本曝光量）** | 论文的「≤1000 update/epoch」本身就是这个曝光量，本单不缩水 |
| bfloat16 混合精度 | **fp32** | CPU 无 bf16 加速 |
| 读出 MLP：LayerNorm(312)→312→256→GELU→dropout .05→256→1 | **LayerNorm(184)→184→256→GELU→dropout .05→256→1** | 随 d_z 变化 |
| 线性读出：P(16) / [P;Z;Δ](272) | **P(16) / [P;Z;Δ](144)** | 同上 |
| 3 个种子 | **2 个种子 {42, 2024}** | 任务书要求 ≥2 |
| 表征 checkpoint 选型的验证子集 | **验证样本每 4 个取 1 个**（确定性抽样） | 论文用整个验证子集；本机 CPU 预算 |
| 读出训练每个日期的样本数 | **每个预测日最多 1,000 只股票**（按 ts_code 排序确定性取前 1,000） | 读出 batch = 一个日期的全部样本；日期级封顶以控预算 |
| 读出 checkpoint 选型的验证子集 | **验证样本每 4 个取 1 个** | 同上 |

**因算力导致的偏离（单列）**：① d_model 128→64；② 层数 4→2；③ 头数 8→4；④ FFN 512→128；
⑤ d_z 128→64（读出输入 312→184）；⑥ fp32 而非 bf16；⑦ 种子 3→2；⑧ 表征与读出 checkpoint
选型用的验证子集按 1/4 抽样；⑨ 读出训练每个日期的股票数封顶 1,000。
**这些偏离会压低绝对水平**（论文 S2 的表达能力被削减），因此本单的结论只对
「同一降级配置下三档之间的相对增量」有效，**不能**用绝对 RankIC 去对标论文 11.22%。

## 10. 方法：三段式实现细节（对齐论文附录 B/C/D）

### 10.1 S1 · 先验（岭回归，α=20）

- 多输出岭回归：`min Σ ‖y − c − Wᵀx̃‖² + α‖W‖²_F`，**截距不惩罚**，α=**20**（论文附录 B）。
- 特征标准化用**块内拟合池**的历史矩；非有限标准化值 → 0；裁剪 [−8, 8]。
- 拟合池 >300 万样本时按样本 ID **确定性抽稀**（论文口径）。
- 残差尺度：`s^res_{b,j} = sqrt(max(mean((e − ē)²), 1e-8))`；`σ^res_{b,j} = log(max(s^res/d_j, 1e-4))`。
- 先验向量 `P = [ŷ^pri(8) ; σ^res(8)] ∈ R^16`，其中 `ŷ^pri = clip((ŷ^raw − m^tr_j)/d_j, −8, 8)`。
- **S1-only 读出**：P(16) → 线性 → 标准化 21 日收益（冻结表征）。

### 10.2 S2 · 表征学习

- 上下文编码器 E_θ 与目标编码器 T_θ̄ **同构**：40 维 → 线性投影到 d_model → 加**可学习 summary token**
  与位置编码 → **pre-norm Transformer 层** → 取 summary token → LayerNorm → d_z。
- 先验投影器 A_φ：`Linear(16→d_z) → LayerNorm → GELU → Linear(d_z→d_z)`。
- 修正预测器 Q_ψ：`concat(H(128→d_z), sg[A_φ̄(P)]) → MLP d_z→d_z→d_z`（GELU + dropout 0.1）。
- 损失（论文 Eq.10 + Eq.29）：
  - `L_anc = E‖Z̃^anc − Z^tgt‖²`（**只更新 A_φ**）；
  - 修正坐标用**游离训练位移 D^trn = sg[Z^tgt − Ẑ^anc]** 的**运行均值/方差**标准化：
    前 100 步用批内均值/方差，之后 EMA 衰减 0.99；`s_k = max(sqrt(v+1e-4), 1e-3)`；
    `d^norm = clip((D^trn − m_k)/s_k, −8, 8)`；`L^impl_rev = E‖q̂ − d^norm‖²`；
    供读出使用的 `Δ̂ = m_k + s_k ⊙ q̂`。
  - 两个损失**等权**；不启用额外潜空间总量损失与正则损失（论文：disabled）。
- **分离更新**：`T_θ̄` 与 `A_φ̄` 用 EMA（衰减分别 **0.996 / 0.99**）更新，不接收梯度、恒为 eval 模式；
  锚点在修正预测器输入与位移目标中**全部 detach**。
- 优化：两个 AdamW（分别更新 A_φ；以及 E_θ + Q_ψ），lr **1e-4**，wd **0.01**，梯度裁剪 **1.0**，
  batch **256**，**4 epoch × ≤1000 update/epoch**。
- checkpoint 选取：验证子集上 `L_anc + L^impl_rev` 最小者。
- 掩码（训练期）：连续 5–21 日时间块随机采样直到遮盖位置 ≥30%，遮盖 token 替换为**可学习 mask token**；
  6 个特征组各自独立以 **0.25** 概率整窗置零；未来窗不掩码；验证/推理关闭掩码。

### 10.3 S3 · 读出（冻结表征）

- 历史摘要 `s = mean(X_std_ctx, 126)` ∈ R^40。
- 输入 `u = [s(40) ; P(16) ; Ẑ^anc(d_z) ; Δ̂(d_z)]`。
- 读出：`LayerNorm → Linear(→256) → GELU → dropout 0.05 → Linear(→1)`，预测**标准化** 21 日对数收益。
- 目标标准化：训练段 21 日收益的均值/标准差（`μ_y^tr, σ_y^tr`）；推理时 `ŷ = μ_y^tr + σ_y^tr·g_ω(u)`。
- 损失：**SmoothL1**（β=1）；优化 AdamW lr **1e-4**、wd **0.05**、梯度裁剪 1.0；
  **每个 batch = 一个预测日的全部可用样本**，每 epoch 打乱日期顺序；**6 epoch × ≤1000 date-group update/epoch**。
- checkpoint：验证子集上样本平均 SmoothL1 最低者。**测试集只在表征与读出 checkpoint 都选定后才评测。**

### 10.4 三档消融（任务书指定 + 1 档附加）

### 10.5 并行基线（FMB-style 线性基线，H2 用）

按论文附录 E：每个训练日单独做**截面正则化回归**，再**平均系数**用于样本外预测；

输入为同一套 40 维描述符（训练段标准化）。该基线**同时**是「最便宜的口径校验」——
先跑通它，确认「数据 → 描述符 → 排序 → 组合 → 净收益」全链无口径错误，再上 S1/S2。

## 11. 主检验量、阈值与失败判据（**原样抄写任务书，不改**）

### 判词规则（写死，预注册里原样抄一遍，跑完不许改）

主检验量 **H1（三段式结构的增量，唯一决定进 / 退的量）**：

- 定义 `ΔRankIC = RankIC_full − RankIC_s1_only`，单位百分点（pp），取各档 ≥2 个种子的中位数。
- 论文基准（**转录自 WORK-453 环 1 评论 Table 4，本单须以论文原文核对**）：5.15% → 11.22%，即 `ΔRankIC = +6.07 pp`。
- **进**：`ΔRankIC ≥ +3.0 pp`（达到论文增量的一半以上且方向一致）→ 判「三段式增量复现成立」。
- **退**：`ΔRankIC ≤ +1.0 pp` 或为负 → 判「未复现」，卡在 S2/S3 无增量这一条。
- **部分复现**：`ΔRankIC ∈ (+1.0, +3.0) pp` → 判「部分复现」，必须写清偏差来自哪一项（样本起点 / 池降级 / 40 维字段自定 / 算力降级 / 掩码 / 成本），并给出翻案条件。

并列检验（不单独决定进 / 退，但必须报，且必须与 H1 结论一起出现）：

- **H2 增量显著性**：`full` vs 线性基线（本单自建 FMB-style 岭回归）的 RankIC 差，**10000 次 block bootstrap** 的 95% CI。若 CI 含 0，判「增量统计上不可证」，**不算失败**，但报告必须原样写这句话。
- **H3 可交易性**：净 SR / AR / MDD / 日均换手（论文 RankIC 11.22 ± 0.24%、净 AR 45.66 ± 5.12%、净 SR 1.50 ± 0.28、MDD −31.09 ± 2.30%，Table 1 / p.8）。净 SR 的 95% CI 下界 > 0 且相对论文缩水 ≤60% → 可交易性成立；**净 SR < 0 → 直接判退**，与 H1 无关。
- **H4 读出消融对照**（Table 5）：R2（加修正）vs R3（加等维上下文），论文 11.26% / 1.87 对 10.13% / 1.79。只报数，不判进 / 退。

失败判据（预先写死，命中哪条就写哪条）：

1. 测试期内有效 bar 覆盖率 <85%，或退市股覆盖缺口 >10%（相对论文 CN ALL 5,669 只口径）→ 判「数据不可用」，停手，不硬跑。
2. 任一必需端点 403/40203 且无合规替代 → 停。
3. 两个种子 `ΔRankIC` 均 ≤ +1.0 pp → 判退。
4. 预注册 commit 时间晚于第一个回测产物的 commit 时间（`git log` 可查）→ 整单结论作废，重跑。
5. 独立复算与建模侧相对差 >1e-6 → 以复算值重出判定，并在报告里列出全部不一致项。

种子报告规则：**必须报 mean ± range，不许只报最好的一次**；只报单种子结果的判定按未交付处理。

### 本单对本判据的补充说明（不改变阈值）

- 「论文基准 +6.07pp」已用论文原文 Table 4 核对一致（S1-only 5.15% → full 11.22%）。
- **H3 的「相对论文缩水 ≤60%」在降级配置下不适用为判据**：算力降级会压低绝对水平（§8）。
  本单仍**照报**该比值，并明确标注「在算力降级配置下，该比值不作为通过/不通过的门槛，
  只作为披露量」。**净 SR < 0 → 直接判退**这一条**照旧生效**。
- **H2 的 bootstrap**：对**逐日 RankIC 差**序列做配对 block bootstrap，block 长度 **20 个交易日**，
  重复 **10000** 次，seed **42**。
