## 0. 冻结要素

| 项 | 值 |
|---|---|
| 维度总数 | **40**（资产级 28 + 市场级 12），与论文一致 |
| 分组 | **6 组**（与论文附录 C 的 6 个掩码组一一对应）：G1 收益与动量 / G2 波动率 / G3 价格区间与估值 / G4 交易活跃与流动性 / G5 市场相对 / G6 市场级 |
| 价格口径 | **后复权 hfq**：`hfq_close(t) = close(t) × adj_factor(t) / adj_factor(该股首个有行情日)`；`hfq_open/high/low` 同式换算 |
| 不复权价格 | 仅 `stk_limit.up_limit/down_limit` 与 `daily.open/close` 同尺度（**涨跌停判定用不复权口径**，与 tushare `stk_limit` 一致） |
| 停牌处理 | 停牌日**保留行**：价格前向填充到上一收盘，`vol=0`、`amount=0`；「有 bar」掩码单独保留用于连续性判定（`data_contracts/field_dictionary.md` §5） |
| 缺失处理 | 非有限值 → 0（标准化后），并裁剪到 [−8, 8]（论文附录 B 口径） |
| 标准化 | 训练段统计量，全流程固定（论文：training-only normalization） |
| 单位 | `vol`=手、`amount`=千元、`total_mv/circ_mv`=万元、`total_share`=万股、价=元 |
| 截断 | 所有滚动窗口只使用 **t 当日及之前**的数据（无前视）；未来窗只用于标签与目标 |

**方向列含义**：`+1` = 数值越高先验上未来收益越高；`-1` = 数值越高先验上未来收益越低；
`0` = **无先验方向**（描述性变量，方向由模型学）。绝大多数描述符取 `0`，这是诚实标注，
不是遗漏。

## 7. 与论文口径的差异（必读）

| 差异 | 说明 |
|---|---|
| 字段名 | 论文**未给**任何字段名，只给「28 资产级 + 12 市场级 / 6 类别」。本清单为自定，**与论文绝对水平不可比**；H1 只判三段式结构的**相对增量**，不判绝对 RankIC 能否到 11.22%。 |
| 宏观 3 维 | 论文正文只说 12 个市场级描述符覆盖「market returns, volatility, dispersion, benchmark dynamics, tradability」**五类**，**未点名** SHIBOR 3M / USDCNH 5 日 / 信用利差（环 1 清单里的这 3 项属推断）。本单**不把任何外部宏观端点列为必需项**：G6 的 12 维全部由库内日频面板聚合得到（见上表逐项来源）。若后续获授权接入宏观端点，应另开一版做敏感性对照，不在本次冻结清单内偷偷换。 |
| 基本面 | `fina_indicator` 的 PIT 口径（`ann_date`）已实测可用（见 `data_probe.json`），但**本单 40 维不纳入基本面**：论文 6 个类别里没有基本面项，纳入会引入 as-of join 的额外自由度并使「40 维自定」的自由度再扩大。 |
| 估值维度 | 论文未说明是否含估值；本单含 `pe_ttm/pb` 两维（`daily_basic` 当日可得，无 PIT 风险），方向按先验标 `-1`。 |
