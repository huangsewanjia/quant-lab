摘要一句话结论

在 680 只中证 300 历史成分股、2676 个交易日（2014-01-02~2024-12-31）上，no_mask 臂的表观 IC 为 0.0077，full_mask 臂为 0.0121（ΔIC = -0.0044）；可实现 Sharpe 则为 -0.580 对 -1.132（ΔSharpe = +0.552，95% CI [0.078, 1.034]）。两个方向都与论文相反：no_mask 的表观 IC 更低（ΔIC 为负），可实现 Sharpe 反而更高（ΔSharpe 为正）；且 95% CI 不含 0，但主检验量要求 ΔSharpe < 0，方向不满足，判词为「未复现」。 但换 seed（43）重跑三臂后 ΔSharpe 变为 -0.5515，符号翻转——此时正确的表述是「本实验功效不足，主检验量的符号未定」，种子 42 的「未复现」只是协议冻结轮次的读数，不能当作稳健结论（见 §11.3）。

判词：未复现（退）

主检验量 ΔSharpe ≡ Sharpe(no_mask) − Sharpe(full_mask) = +0.5516， 1000 次配对 block bootstrap（block=20，seed=42）的 95% 百分位区间 [+0.0780, +1.0342]，区间不含0。

辅证 ΔIC ≡ IC(no_mask) − IC(full_mask) = -0.0044， 表观 IC 方向与论文相反（no_mask 更低）。按预注册 §9.4：ΔSharpe < 0 且 95% CI 不含 0 才判「复现成立」；两者缺一即判「未复现」，并在 §11 写明差多少与翻案需要动哪一个口径。

稳健性警告（必读，判词的适用范围因此受限）：本判词按预注册 §9.4 在协议冻结轮次（seed 42）上机械判定。但换 seed（43）、用同一套协议、同一份数据、同一批因子重跑三臂后，ΔSharpe = -0.5515（95% CI [-1.0867, -0.1381]，区间不含 0），按 §9.4 的机械规则会得到相反的判词；两轮的 ΔSharpe 量级几乎相同而符号相反。这说明本实验在可实现 Sharpe 轴上功效不足：主检验量的符号不由数据决定，而由训练随机种子决定。因此本单能站住的结论只有两条：① 协议冻结轮次（seed 42）的判词是「未复现（退）」；② 表观 IC 轴的方向在两个 seed 下同为负（-0.0044 / -0.0021），即「去掉掩码并没有让表观 IC 上升」这一条对种子稳健；而可实现 Sharpe 轴不能下结论（详见 §11.3）。

6组合构建与成本

逐日重解凸 QP：max μ̂ᵀw − α·wᵀΣ̂w，α=10，只做多、单票上限 3%、权重和 = 1； 协方差为 Ledoit–Wolf（120 个交易日回看，PSD 下限 1e-10）。求解器为自写投影梯度法 （等式–箱约束的欧氏投影用二分水位法精确求），在 5 个随机交易日与 scipy.optimize.minimize(method='SLSQP') 交叉校验。

求解器交叉校验：两个口径都超阈，门槛第 6 条判「未通过 / 有条件」。 预注册 v1.0 §8 只写「相对差 ≤1e-6」而未写明分母，预注册修订 v1.4 已把两个口径写死 并采用合取判定（两个口径都 ≤1e-6 才算通过）。实测： 权重口径最大相对差 4.687e-03（15 / 15 个抽样日实例全部超阈， 相当于阈值的数千倍）；目标函数口径最大相对差 1.272e-06， 其中 1 / 15 个实例同样超阈（no_mask 的 2023-12-18，1.272e-06）。 两个口径都超阈，不能只挑一个恰好能过的口径把这一门写成「通过」——因此本单如实标 未通过 / 有条件。

这个缺陷会不会翻掉判词？——单独量化，结论是不会。 权重差异来自目标函数在平坦子空间上的平移（½·H·‖δ‖² 与 SLSQP 的 ftol 同阶）， 两个解的目标函数值几乎相同。为把「几乎相同」变成可核验的数字，本单新增 scripts/work449_solver_materiality.py：把抽样日的权重换成 SLSQP 解， 构造反事实收益序列（扰动只落在 t 与 t+1 两天），重算三臂 Sharpe 与 ΔSharpe。 实测材料性上界：探针自检显示投影梯度解逐位复现交付权重（最大绝对差 0.0e+00），说明它重建的是同一天同一个问题；把抽样日换成 SLSQP 解后，8 bps 口径的 ΔSharpe 从 0.551644 变为 0.551638（扰动 5.753e-06，材料性上界 2.073e-05，仅占 |ΔSharpe| 的 0.0038%）；5 bps 口径下扰动 5.615e-06，占 |ΔSharpe| 的 0.0053%。两档成本下判词均未翻转。 该上界不参与门槛判定（门槛只看上面的合取规则），它的作用是把 「求解器两解不一致」与「结论是否成立」这两件事分开——前者是真的，后者不受影响。

8主检验量与判定

主检验量 ΔSharpe ≡ Sharpe(no_mask) − Sharpe(full_mask)（方向已按派单卡对齐：ΔSharpe 为负即方向复现）。 统计口径为配对 block bootstrap：对两臂同一批测试日的逐日净收益序列做同步重采样 （block = 20 个交易日，块内连续、块间独立，1000 次，seed = 42），统计量是每次重采样的 ΔSharpe， 报 95% 百分位区间。bootstrap 只跑这一套设定，不因结果不理想而改次数或块长。

三处统计口径的显式披露（预注册修订 v1.4 §3）。 ① 块长 20 带来的尾部截断：测试段 726 个交易日、块起点 726 // 20 = 36， 可达下标仅 0..719 ⇒ 尾部 6 个交易日（0.83%）在任何一次重采样中都不会被抽到； 年化跨度按可达比例 720 / 726 等比缩放。对 CI 的影响可忽略，但必须写明， 否则读者会以为 726 日全部可达。 ② 年化用的自然日跨度：end − start = 1092 天（不含末日；含首尾应为 1093）， 影响年化收益 0.09%；三臂与两档成本用同一口径 （delta_sharpe_consistency_abs_err = 0.0），不影响任何相对比较。 ③ 成本口径对 ΔSharpe 的贡献：full_mask 的日均双边换手 0.5618 是 no_mask 的 2.19 倍（no_mask 日均 0.2563）——掩码越严，换手越高、成本越高。8 bps 下 ΔSharpe = +0.5516，5 bps 下 = +0.4070，两者之差 +0.1447（占 |ΔSharpe| 的 26%）就是成本口径本身贡献的部分，其余来自毛收益。两档成本下 ΔSharpe 都为正、判词都是「未复现」，因此结论对成本假设稳健；读者不应把 +0.55 整个当作 alpha 差异。

11失败、限制与已知缺口

  • 本单最重要的一处自查：首版实现把 ts_rank 的「窗口最后一个元素」取成了 「最后一列股票」，导致该因子值全为 0、训练段样本被清空（train loss = 0、验证 RankIC = NaN）。 根因是 numpy 的 sliding_window_view 与官方 torch 的 unfold(...).permute(...) 窗口轴位置不同。现已把移植改成与官方 逐字直译，并新增 scripts/work449_test_primitives.py： 把官方 torch 原语转写为参考实现，与 numpy 移植逐格比对，6 个原语 × 3 种窗口 × 6 组随机面板， 掩码 0 处不一致、值最大相对差 1.1e-13（ts_rank 5.7e-8，源于官方把 rank 转 float32）。
  • 协议一致性缺陷（已修）：首版面板按「有源数据行」建掩码，导致 no_mask 臂读不到停牌格， 违反预注册 §5.2「no_mask 读取全部格子」；现改为稠密网格，停牌日按 field_dictionary §5 前向填充后照读。
  • 预测错位（已修）：首版把模型输出落在 t+1，导致组合用的是一天的陈旧预测； 现按预注册 §9.2 统一为 ŷ_t 对 r_{t+1}，组合在 t 用当日信号建仓。
  • ST 区间残缺：Tushare stock_st 端点返回 40203（无权限）， 改用 namechange 取 ST 区间，池内命中 7 只。 由此漏判的 ST 涨跌停事件上界为测试窗 148 格——这会同时压低三臂的 at_limit 掩码， 对 ΔSharpe 的影响方向不明（属已知限制，未做额外修正）。
  • 退市/长期停牌的尾部：20 只股票的最后一个源数据行早于 2024-12-01， 其后的格子按「无行」处理（而非停牌），属保守口径。

  1. 输入因子本身有可观的截面信息：同一组 12 个因子的单因子测试段 RankIC |IC| 全距达 0.0004 ~ 0.0579（中位 0.01345， 其中 5 个 ≥ 0.03、6 个 ≤ 0.0161），闭式 OLS 基线的测试段 RankIC 为 +0.01463（t = 3.35），而训练出的 MLP 只有 0.00767。 信号存在，是模型把它压掉了。
  2. 不是「AdjMSE 偏好常数解」：训练集上的 AdjMSE = 4.931452e-04， 而最优常数预测器是 4.319777e-04——模型在训练目标上甚至不如一个常数， 排除了「损失函数的常数吸引子」这一解释，指向优化没走完。
  3. 但模型类不是问题：在协议允许的选择用数据（2021 验证段）上， 冻结口径的 MLP + AdjMSE 是四个配置里验证 IC 最高的一个； 换成线性模型反而更差。所以「MLP 选错了」不成立， 成立的是「这个规模的数据 + 这个训练预算下，训练结果本身不稳」。

由此得到本单最重要的稳健性警告。上表最后一列显示：同样的协议， 换一个 seed，测试段 IC 就会大幅移动——冻结口径的 MLP+AdjMSE 在 seed 42 / 43 上分别是 +0.0092 / +0.0240，线性+AdjMSE 则是 −0.0043 / −0.0443。原因不难理解：AdjMSE 的权重由 sign(pred)·sign(target) > 0 决定，而预测值恰好在 0 附近时 符号是不连续的，于是极小的数值扰动（线程数、浮点归约顺序）就会被放大成 不同的训练轨迹。
后果：主检验量 ΔSharpe 的 bootstrap 95% CI 只覆盖收益序列的抽样噪声， 不覆盖模型/seed 随机性。因此 ΔSharpe 的量级（+0.55）不可当作 精确效应量；符号是否稳健，必须靠换 seed 复跑三臂来验，本单在 §11.3 给出该检验的结果。

对此本单做了什么、没做什么。诊断脚本 scripts/work449_model_diagnostic.py 在完全相同的数据、样本集、 归一化、优化器、学习率、batch、epoch 数、梯度裁剪与 seed 下，只改模型类与损失两个变量， 并分别在 2021 验证段（协议允许的选择用数据）与测试段（仅作观察）报告逐日 RankIC。 本单没有据此改模型类、改正则、改超参或加 epoch——那会构成「看结果后调口径」， 并违反预注册 §9 的样本外纪律。结论因此限定为： 「掩码背离方向未复现」这一判断成立于三臂之间的相对比较； 本单的绝对水平（Sharpe 全为负、IC 远低于论文）受此限制影响，不能反过来当作「论文成立」的证据。
