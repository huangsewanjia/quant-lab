## 澄清 1 · 涨跌幅档与板块规则的优先级

**v1.0 初稿的问题**：写明「±10% 涨跌停」与「ST 5%」与「科创板/创业板 20%」并存，但没说三者冲突时谁优先。

**唯一读法**：

- **ST 的 5% 档只作用于主板**；ST 股不享受板块 20% 档。
- **科创板（688/689）20%**；**创业板（300/301）自 2020-08-24 起 20%**，该日之前 10%。
- **北交所 30%**（本轮主池不含北交所股，为口径完整性保留）。
- 与官方实现 `initial-d/ml-quant-trading` 的 `features/bias.py:board_limit_pct` **逐条一致**：主板 0.098 / 创业板·科创板 0.198 / 北交所 0.298，创业板在 2020-08-24 之前回落 0.098。

**代理阈值表（本单取用）**

| 板块 | 涨跌停带 | 代理阈值（`limit_pct`） |
|---|---|---|
| 主板（非 ST） | 10% | 0.098 |
| 主板（ST，`isST=1`） | 5% | 0.048 |
| 创业板（300/301，2020-08-24 起） | 20% | 0.198 |
| 创业板（300/301，2020-08-24 前） | 10% | 0.098 |
| 科创板（688/689） | 20% | 0.198 |
| 北交所（4/8/92 开头） | 30% | 0.298 |

**实测备注**：`000300.SH` 成份股按指数编制规则**不含 ST 股**，故 ST 档在本池最多影响极少数「后来被 ST 但历史上在池内」的股票日格；该影响格子数须在产物中单独计数并报告。

## 澄清 2 · 回退阈值不得统一套用

**v1.0 初稿的问题**：回退阈值固定写 0.098（10% 档口径）。若对创业板 / 科创板统一套 0.098，会把普通的 ±10%~±19% 波动**误判成涨跌停**，把不该被掩码的格子掩掉，直接压低 `full_mask` 臂的有效样本量并扭曲 ΔSharpe。

**唯一读法**：

- 回退阈值**随板块取 0.098 / 0.198 / 0.298**（主板 ST 为 0.048），与 `board_limit_pct` 一致；
- **禁止**统一套用 0.098；
- 若数据源提供交易所公布的涨跌停价（`limit_up` / `limit_down`），**优先**用公布价，判据 `close ≥ limit_up − ε` 或 `close ≤ limit_down + ε`，`ε = 1e-3`；仅在**没有**公布价时才回退到收益代理。

**本轮实际情况**：baostock 不提供公布涨跌停价 → 走收益代理路径；代理用的收益用**不复权**的 `close/preclose − 1`（`preclose` 为除权无关的前收盘），**不用**前复权价算涨跌幅，避免除权日被误判成涨跌停。

## 澄清 3 · 窗口断言的触发语义

**v1.0 初稿的问题**：「`halt_only` 臂必须不触发窗口断言」与「`halt_only` 涨跌停日可读」自相矛盾——涨跌停日本身就是 `M_exec = 0`，若它的价格进了滚动窗口，依赖窗口里就含 `M_exec = 0` 的格，断言**理应**触发。

**唯一读法**：

- **断言语义**：某臂任一因子的任一**有效输出格**，其**依赖窗口内含 `M_exec = 0` 的格** → 触发。
- 三臂期望：

| 臂 | 断言期望 | 理由 |
|---|---|---|
| `no_mask` | **必须触发**（计数 > 0） | 因子读了停牌日与涨跌停日，这些格 `M_exec = 0` |
| `halt_only` | **必须触发**（计数 > 0） | 停牌日已被掩，但**涨跌停日仍可读**，其 `M_exec = 0` |
| `full_mask` | **必须不触发**（计数 = 0） | 因子只读 `M_exec = 1` 的格，依赖窗口内不可能出现 `M_exec = 0` |

- **退出门槛第 3 条的判据与强度不变**：三行期望即判据，任何一行不符即判 blocking。
- **断言必须能证明自己在跑**：三臂各自的触发计数写进产物 JSON；`no_mask` 与 `halt_only` 计数为 0 视为断言失效（blocking）。

## 结论

本澄清件**未改动** v1.0 的任何数值：样本窗（训练 2015–2020 / 验证 2021 / 测试 2022–2024）、股票池（`000300.SH` 生效日名单 + §2.2 功效回退规则）、成本（8 bps 主口径 + 5 bps 敏感性）、组合约束（只做多、单票 3%、每日调仓）、因子集（12 个）、模型（MLP + AdjMSE γ=0.1）、主检验量（`ΔSharpe ≡ Sharpe(no_mask) − Sharpe(full_mask)`）、判定规则（`ΔSharpe < 0` 且 1000 次 block bootstrap 95% CI 不含 0 → 复现成立）、退出门槛 7 条——**全部保持不变**。
