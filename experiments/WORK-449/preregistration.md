## 1. 研究问题与可证伪假设

**主假设 H1（掩码背离）**：在公开 A 股日频数据上，**不施加涨跌停掩码**会让模型的**表观 IC 上升**、但**可实现 Sharpe 下降**——因为涨跌停股的收益在截面上「可预测」却**不可成交**。

**主检验量**（唯一定义，符号写死）：

```
ΔSharpe ≡ Sharpe(no_mask) − Sharpe(full_mask)        ← 主检验量
ΔIC     ≡ IC(no_mask) − IC(full_mask)                  ← 辅证量（不作为闸门）
```

**复现成立（H1 成立）** ⟺ ① `ΔSharpe < 0` **且** ② `ΔSharpe` 的 **1000 次 block bootstrap 95% CI 不含 0**。
**未复现** ⟺ ① `ΔSharpe ≥ 0`，或 ② CI 含 0。**「未复现」仍然算交付**（写清「未复现」并给实测值）。

**辅证（报告用，不参与判定）**：`ΔIC > 0` 表示「去掉掩码后表观 IC 反而上升」，即论文所述背离的另一半；`ΔIC ≤ 0` 时结论仍按上条判，但必须在正文写明「背离只复现了一半」。

**H1 的可证伪性**：若 `ΔSharpe ≥ 0`（去掉掩码后 Sharpe 不降反升），则「掩码造成 IC–Sharpe 背离」在本池本窗口**被证伪**；本单仍须交回三档全部实测值。

**不追的东西**：不追论文的 Sharpe 1.63 绝对水平（专有面板不可得），不复刻 213 个因子，不做 LLM 因子挖掘，不产出投资建议、评级或目标价。

### 2.2 功效检查与**预注册**回退规则（机械执行，不看结果再定）

**为什么需要**：掩码背离的检验功效由「测试窗内被掩码的股票日格数」驱动。CSI 300 成分股体量偏大，涨跌停事件密度低于论文的全 A 池；若掩码几乎不生效，ΔSharpe 的差异会来自噪声而不是掩码口径。

**规则（写死）**：

1. 在**模型训练与回测之前**，先只用**测试窗**（2022-01-01 ~ 2024-12-31）的原始面板计算 `full_mask` 掩码率 = 被掩码的股票日格数 ÷ 该窗内有效股票日格总数。
2. 若 **掩码率 ≥ 0.50%** → 股票池**锁定为 `000300.SH`**，按本文件跑到底。
3. 若 **掩码率 < 0.50%** → 股票池**锁定为 `000300.SH ∪ 000905.SH`（沪深 300 ∪ 中证 500）**，同样按**生效日名单**建仓；最终报告以**锁定后的池**为主结果，并把池口径写进报告首页。
4. 掩码率是一个**只看数据覆盖、不看模型结果**的量；本规则在**任何回测产物产生之前**执行，执行记录（掩码率数值、锁定到的池）写入 `experiments/WORK-449/failure_log.md` 的 F26 条目。
5. **不允许**在看到 ΔSharpe / ΔIC 之后再改池；一旦锁定，不得变更。

### 4.3 已知坑与预注册的复权伪跳变修复规则

**已实测的坑（前一版跑批中发现，已写入本协议）**：某些前复权序列在除权日会出现**物理上不可能的跳变**（实测出现过隐含调整后收益达数十倍）。真实除权日的隐含调整后收益必然落在涨跌停带内，因此可以用涨跌停带做判据。

**修复规则（冻结）**：设复权因子 `f(t) = close_qfq(t) / close_qfq(t−1)`，隐含调整后收益 `imp(t) = f(t)/f(t−1) − 1`。若 `|imp(t)| > band(t) × 1.02 + 0.01`（`band` = 该股该日所属板块的涨跌停带：主板 0.10 / 创业板·科创板 0.20 / 主板 ST 0.05 / 北交所 0.30），则判该股该日的**前复权价损坏**，该日改用不复权口径处理（`f(t) = f(t−1)`，即当日不参与复权换算）。跨停牌行对跳过。

**报告要求**：修复前后的结果**都报**（三档数值 + ΔSharpe + 判定档位 + 产物 sha256）；判定规则、主检验量、阈值、退出门槛**全部不变**；若判定档位在修复前后不同，两个数字都报，不只报有利的一侧。

**本轮不使用腾讯 `fqkline`**：前一轮已实测其前复权序列存在伪跳变（600519 在 2017-01-04 出现 +40.3% 级伪跳变，同日 baostock 给 +5.19% 真实值），属正确性问题而非限流问题。

## 5. 掩码三档（**核心，写死**）

### 5.1 两个掩码，职责分开

| 掩码 | 定义 | 作用范围 |
|---|---|---|
| **`M_exec`**（执行掩码） | `M_exec[t,i] = 1` ⟺ 该股当日**未停牌** ∧ **未涨跌停** ∧ **已上市满 1 年** | **三臂共用**，是市场事实：当日能否成交 |
| **`M_factor`**（因子/标签掩码） | 随臂变化，见 §5.2 | 因子计算与标签构造读哪些格 |

**涨跌停判定**（`features/bias.py` 口径）：
- 有交易所公布的涨跌停价时：`close ≥ limit_up − ε` 或 `close ≤ limit_down + ε` → 不可成交，`ε = 1e-3`；
- 无公布价时（baostock 源）用**收益代理**：`|r_t| > limit_pct` 即判涨跌停，`limit_pct` 随板块取 **0.098 / 0.198 / 0.298**（主板 ST 取 **0.048**），`r_t` 用**不复权**的 `close/preclose − 1`；
- **首个交易日恒被掩码**（无前收盘可比），与官方实现一致。

### 5.2 三档定义（**每档一句话，顺序不可换**）

| 臂 | `M_factor` 定义（一句话） | 掩码生效时点 |
|---|---|---|
| **`no_mask`** | 不施加任何掩码，因子与标签读取**全部**格子（停牌行价格按 `field_dictionary.md` §5 前向填充，属数据事实而非掩码） | — |
| **`halt_only`** | 只施加**停牌**掩码（停牌日不可读），**涨跌停日可读** | 掩码先于滚动窗口生效 |
| **`full_mask`** | 施加**停牌 + 涨跌停**掩码（等价于 `M_exec`），涨跌停日不可读 | 掩码先于滚动窗口生效 |

**三档的唯一变量就是 `M_factor`。** `M_exec`、成本、组合约束、调仓频率、模型结构、训练协议在���臂完全一致。

### 5.3 「掩码先于滚动窗口生效」（**写错则整单结论作废**）

掩码在**数据加载期**构造，先于任何滚动算子执行；滚动算子**只读 `M_factor=1` 的格子**：

- `ts_mean`：`Σ(x·mask) / max(Σmask, 1)`，输出掩码 = `Σmask > 0`；
- `ts_std`：同上，输出掩码 = `Σmask ≥ 2`；
- `ts_corr`：在窗口内的有效格子上求 Pearson，输出掩码 = `Σmask ≥ 2`；
- `ts_rank`：窗口内有效格子中最后一个值的排名 / 有效格数，输出掩码 = **窗口内全部有效**；
- `ts_min` / `ts_max`：窗口内有效格子的最小/最大值，输出掩码 = 窗口内**至少一个**有效格；
- 通用三条性质（论文 §A.3）：① 输出格在被掩码处为 0；② 输出格**不依赖**任何被掩码输入格的值；③ 输出掩码不会比输入掩码更宽松。

**被掩码格的值不参与任何聚合**（`masked_fill` 口径），因此「掩码先于窗口」= 掩码格既不进分子也不进分母。

### 5.4 窗口断言（引擎必须有，且必须能证明它在跑）

断言：**某臂任一因子的任一有效输出格，其依赖窗口内含 `M_exec = 0` 的格** → 触发告警。

| 臂 | 期望 | 理由 |
|---|---|---|
| `no_mask` | **必须触发** | 因子读了涨跌停/停牌日，这些日的 `M_exec=0` |
| `halt_only` | **必须触发** | 涨跌停日仍被读入，其 `M_exec=0` |
| `full_mask` | **必须不触发** | 因子只读 `M_exec=1` 的格，依赖窗口内不可能有 `M_exec=0` |

**退出门槛第 3 条的判据即此三行**，强度不变。断言实现为引擎内 `assert` / 计数器，运行时把三臂各自的触发计数写进产物 JSON。

### 5.5 执行约束（三臂共用，来自派单卡「涨跌停日下单量按 0」）

- 权重滞后一期使用：`w_{t−1}` 承担 `t` 日收益（`r_net,t = w_{t−1}ᵀr_t − c·‖w_t − w_{t−1}‖₁`）。
- **下单约束**：在 `M_exec[t,i] = 0` 的股票上，**当日下单量按 0**（不可买入、不可卖出）。
- **持有约束**：持仓股进入涨跌停日后仍**持有**并赚取该日收益（不假设能卖出），但**不新开仓**；已持有部分在不可成交日保持权重不变。
- 该约束是**引擎的硬约束**，三臂一致；掩码只改变**模型看到什么**，不改变**引擎能做什么**。

| F11 | `range_1` | `(high_t − low_t)/close_t` | 1 | 价量 | 否（单日） |
| F12 | `amt_proxy_20` | `ts_mean(amount, 20)`，无 `amount` 时用 `volume×close` 代理 | 20 | **流动性/价量** | **是（滚动算子）** |

- **截面中性化**：每个交易日对全部因子做**去极值 + 标准化**（MAD 去极值，阈值 5 倍；随后 z-score），**在 `M_factor` 内做**（被掩码格不参与均值/标准差计算）。
- **不选因子**：因子集**在预注册冻结**，不做前向选择（避免多重检验）。
- 因子值缺格（依赖窗口无效）→ 该样本不参与训练/预测。

| 项 | 规定 | 依据 |
|---|---|---|
| **架构** | **MLP**（二选一选 MLP） | 论文 §3.5.3：MLP = 2 个隐藏层（128 单元，GELU，dropout 0.1），线性输出到标量；Transformer 是同架构的另一选择。本单选 MLP：**参数更少（约 1 万级 vs 论文 44K）、训练更快、对本单的小因子集更合适**，且论文 Table 11 的结论在 MLP 上同样成立（论文 Table 12 显示 MLP 与 Transformer 差距 ≤0.05 Sharpe） |

## 9. 主检验量、统计口径与判定

### 9.1 每臂必报指标（缺一不可）

`表观 IC`（逐日 Pearson(预测收益, 已实现次日收益) 的截面均值，再对测试日取均值）、`可实现 Sharpe`、`年化收益`、`年化波动`、`MDD`、`单边/双边换手`、`测试期天数`、`平均有效股票数`、`掩码率`、`窗口断言触发次数`。

### 9.2 表观 IC 的定义（写死）

- 逐日：在**该臂的有效股票集合**（因子有效且标签有效）上，算 `corr(ŷ_t, r_{t+1})`（Pearson）。
- 该臂的 `no_mask` 臂里，`r_{t+1}` 包含**涨跌停日不可成交的收益** → 这正是「表观」的含义。
- 测试段逐日 IC 的**均值**为该臂表观 IC；同时报**逐日 IC 的标准差**与 **IC t 统计量**（均值 / (std/√T)）。

### 9.3 Block bootstrap（写死）

- 配对 bootstrap：对 `no_mask` 与 `full_mask` 两臂的**同一批测试日**逐日净收益序列做**同步重采样**（保持两臂日期配对）。
- **1000 次**重采样；**block 长度 = 20 个交易日**（块内连续，块间独立）；随机种子 `42`。
- 统计量 = 每次重采样的 `ΔSharpe`；报告 **95% 百分位 CI**（2.5% / 97.5%）。
- **不得**用样本外结果反复调参：bootstrap 只跑一次设定（1000 次 / block 20 / seed 42），不因结果不理想而改次数或块长。

### 9.4 判定词（写死两档）

- **复现成立**：`ΔSharpe < 0` 且 95% CI 不含 0 → 判词「**进**」，并写明 `ΔIC` 是否 > 0（背离是否完整复现）。
- **未复现**：`ΔSharpe ≥ 0` 或 CI 含 0 → 判词「**退**」，写清卡在哪一条（差多少、CI 覆盖范围），以及**翻案需要什么**（换池 / 换窗口 / 换因子集 / 换成本口径中的哪一个）。
