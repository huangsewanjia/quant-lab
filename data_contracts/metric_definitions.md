# 指标定义

> **作用**：把「一个指标怎么算」写死，避免同名不同义。
> 本文件是跨实验复用的资产。对外报出的任何指标，其名字必须能在这里查到定义与已知偏差。
>
> 口径基线：WORK-404 快照（`experiments/WORK-404/`），窗口 2025-01-02 ~ 2026-11-13。

---

## 1. 基础量

| 指标 | 定义 | 公式 | 单位 |
|---|---|---|---|
| **日收益** | 收盘对收盘的涨跌幅 | `r_t = close_t / close_{t-1} − 1` | — |
| **区间收益** | 窗口内收盘到收盘 | `R = close_end / close_start − 1` | % |
| **自然日数** | 区间两端日期的日历差 | `days = (date_end − date_base).days` | 天 |
| **交易日数** | 区间内有效日收益的个数 | `n_days = len(r_t)` | 天 |
| **基准日** | 窗口起点**之前**最后一个交易日收盘 | `close_base = close[date ≤ start − 1 day]` | 点 |

> 端点规则见 `field_dictionary.md` §4：端点取「≤ 目标日的最后一个交易日」，不硬编码交易日。

---

## 2. 年化

| 指标 | 定义 | 公式 | 备注 |
|---|---|---|---|
| **年化收益** | 区间收益按**自然日**折算 | `ann = (1 + R)^(365.25 / days) − 1` | 用自然日而非交易日：区间两端可能跨节假日，日历折算更贴近持有期。 |
| **年化波动** | 日收益标准差按**交易日**折算 | `vol = std(r_t) × √252` | **必须用 √252**，不能混用 365.25。 |
| **两者的分母不同是刻意的** | 收益按日历时间积累，波动按交易日频率采样 | — | 混用会让「低波动日」被高估。 |

> **基准点**：`base_date` 是**基准日**（起点前最后一个交易日），不是区间首个交易日。`days` 从基准日算到区间末日。

---

## 3. 夏普

| 指标 | 定义 | 公式 |
|---|---|---|
| **夏普比率（rf = 1.5%）** | 超额年化收益除以年化波动 | `sharpe = (ann_return − 0.015) / ann_vol` |

| 参数 | 取值 | 说明 |
|---|---|---|
| 无风险利率 `rf` | **1.5%（年化）** | 本仓库固定值。改 `rf` 必须同步改 `metric_definitions.md`、脚本常量与实验登记表的参数列，否则跨实验不可比。 |
| 波动为零时 | 夏普记为 `null`，**不记 0** | 0 会被读成「表现平平」，`null` 才是「不可计算」。 |
| 样本不足 | 不足 1 年不报夏普，只报区间收益与波动 | 年化外推误差大。 |

---

## 4. 最大回撤

| 指标 | 定义 | 公式 |
|---|---|---|
| **最大回撤（MDD）** | 区间内收盘价从历史峰值的最深跌幅 | `MDD = min(close_t / cummax(close)_t − 1)` |

| 规则 | 内容 |
|---|---|
| 起点 | **YTD 基准日 2025-12-31**（不是快照首日 2025-01-02） |
| 粒度 | **日收盘**，不是日内最低价 |
| 符号 | 负值（如 −31.20% 表示回撤 31.20%） |
| 空窗口 | 区间内无数据 → 记 `null`，不记 0 |
| 与「距年内高点回撤」的区别 | 前者是**区间内**MDD；后者要相对区间内最高点单独计算，二者不是同一口径，对外报数必须写清用的是哪个。 |
| **口径变体（必读）** | 本仓库默认**收盘 cummax**。但媒体 / 原文引用的「期间最大跌幅」**可能不是收盘口径**——实测：某原文的「中证1000 期间最大跌幅 31.39%」只在**日内最高→最低**口径下对上（实测 −31.39%，差 0.001pp），而收盘 cummax 口径为 −30.59%（成立以来）/ −31.20%（YTD 起点）。**当实测与原文对不上时，先试 4 种回撤口径再判「站不住」**：① 区间内收盘 cummax；② 区间内日内最低 cummax；③ 区间内最高→最低；④ YTD 起点收盘 cummax。详见 `docs/second_article_trial.md` D2。 |

## 5. 换手率

| 指标 | 定义 | 公式 |
|---|---|---|
| **单边换手** | 一期内持仓变动占组合权重的比例 | `turnover = Σ|w_t − w_{t−1}| / 2`（单边）或不除 2（双边） |
| **双边换手** | 买入额 + 卖出额占组合规模 | `2 × 单边换手` |
| **年化换手** | 区间换手按时间外推 | `turnover_ann = 区间换手 / years` |

| 规则 | 内容 |
|---|---|
| 报告时必须声明 | **单边还是双边**，以及是否年化。 |
| 成本挂钩 | 换手 → 成本 → 净收益，三者必须同口径报告，不允许只报换手不报成本假设。 |
| 指数型策略的换手 | 指数成分调整带来的被动换手。**成分调整规则未公开时，换手只能标为「需要假设补全」，不得给数字。** |

> **本仓库当前状态**：**尚无实测换手率**。WORK-404 实验对象是指数行情而非组合，没有持仓与权重，换手无法从快照推出。
> 下一次实验做组合级回测时，按上表口径产出，并在 `experiments/registry.md` 登记换手与成本假设。

## 6. 成交额代理口径（单独一节：本仓库最易被误用的指标）

### 6.1 定义

```
turnover_proxy(元) = volume(股) × close(元)
```

这是**本仓库的计算列，不是任何数据源的原始字段**。

### 6.2 为什么会有代理

本轮真实成交额 `amount` **取不到**：
- 东方财富 push2 对本机出口 IP 限流（12 / 12 全部 `skipped`）；
- 网易财经 CSV 稳定 `HTTP 502`。

两个备选源都失败，因此全市场成交额只能用 `volume × close` 代理。

### 6.3 偏差量级与适用范围

| 项 | 值 | 证据 |
|---|---|---|
| 2026-09-30 代理值（中证全指） | 4.930 万亿元 | `metrics.json → turnover_proxy_validation` |
| 2026-09-30 真实成交额（Tushare `amount`） | 1.382 万亿元 | 同上 |
| **比值** | **3.57** | 同上 |
| 2026-10-30 代理值 | 5.282 万亿元 | 同上 |
| 2026-10-30 真实成交额 | 1.618 万亿元 | 同上 |
| **比值** | **3.26** | 同上 |
| **比值区间** | **3.3 – 3.6 倍** | 两点比值稳定 |

**偏差的来源**：指数成交量是**成分股成交量加总**，而指数点位**远高于成分股均价**。两者相乘自然把成交额放大数倍。

### 6.4 使用规则（硬规定）

| 允许 | 禁止 |
|---|---|
| 判断成交额**趋势方向**（缩量 / 放量） | 报**绝对成交额**（如「10 月全市场成交额 5.11 万亿元」） |
| 比较**同一指标自身**的时间序列变化（如 10 月较上半年均值 −42.6%） | 把代理值与任何**真实成交额**并排比较 |
| 检验「成交活跃度回落」这类**相对**前提 | 用代理值反推冲击成本或滑点量级 |

> **每次使用代理口径，三处都要写明**：① 图注；② 指标表脚注；③ 报告正文。缺一处即视为口径未声明。

### 6.5 代理口径的敏感性声明

原文「成交缩量」的判断是**相对趋势判断**，用代理检验成立（10 月较上半年均值 −42.6%）。但「缩量 → 超额被吃掉多少」**无法量化复现**：原文未给冲击成本模型，且真实成交额本身未取到。

## 7. 风格相对收益差

| 指标 | 定义 | 公式 | 单位 |
|---|---|---|---|
| **风格差** | 同一窗口内两个指数收益之差 | `spread = R_A − R_B` | **百分点（pp）** |

| 规则 | 内容 |
|---|---|
| 单位 | 恒为**百分点**，不写 %（避免与相对涨跌混淆） |
| 配对 | 预先写死的配对表（`build_analysis.py: pairs`），不事后挑配对 |
| 方向 | 正 = A 跑赢 B；报告中必须点明谁是谁 |
| ≠ 超额 | 基准差**不能**当作策略超额亏损（WORK-404 的 B2 第 5 条已踩过这个坑） |

---

## 8. 隐含超额下界

当原文只给出一个**方向与量级**的产品指数表现（产品本身无公开行情），可用基准反推下界：

```
若 私募指数 10 月收益 ≤ −17.0%
且 基准指数 10 月收益 = −15.59%
则 隐含超额 ≤ −17.0% − (−15.59%) = −1.41 个百分点
```

| 规则 | 内容 |
|---|---|
| 性质 | 这是**条件推导**，前提是「原文的 −17% 成立」。前提未经独立核验 → 结论强度受限于前提。 |
| 口径敏感性 | 换基准指数、换区间 → 结论变。**三套以上口径必须全部报出**，不挑最优。 |
| 禁止 | 不得把条件推导写成「实测超额」。 |
