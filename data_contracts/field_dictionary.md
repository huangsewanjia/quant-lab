# 字段字典

> **作用**：把「一个数字长什么样」写死——单位、时区、频率、缺失规则、复权方式、生效时间、对齐方式。
> 本文件是跨实验复用的资产。任何新实验引入新字段，必须先在本表登记，再进代码。
>
> 口径基线：WORK-404 快照（`experiments/WORK-404/snapshot_manifest.json`），数据窗口 2025-01-02 ~ 2026-11-13，采样 2026-11-15。

---

## 1. 字段定义

| 字段 | 含义 | 单位 | 时区 | 频率 | 缺失规则 | 复权 / 生效时间 |
|---|---|---|---|---|---|---|
| `date` | 交易日 | `YYYY-MM-DD` | Asia/Shanghai | 日 | 非交易日**无行**；节假日直接缺行，**不补 0、不前向填充** | — |
| `open` / `close` / `high` / `low` | 指数点位 | 点 | 同上 | 日 | 不允许 NaN（S-A 实测无缺失）；出现 NaN 即判该快照不合格 | **指数无除权处理**（指数点位是编制定值，不随成分股除权调整） |
| `volume` | 成交量 | **股**（S-A） | 同上 | 日 | 无 | — |
| `vol`（Tushare） | 成交量 | **手**（1 手 = 100 股） | 同上 | 日 | 无 | 与 S-A 的 `volume` 相差 100 倍，换算已验证 |
| `amount`（Tushare） | 成交额 | **千元** | 同上 | 日 | 无 | 换算为元需 × 1000 |
| `turnover_proxy` | **成交额代理**（本仓库计算列，**非源字段**） | 元 | 同上 | 日 | 无 | = `volume(股) × close(元)`；**只用于趋势/相对比较，绝对水平不可用**，偏差倍数见 `metric_definitions.md` §6 成交额代理口径 |
| `pct_chg`（Tushare） | 收盘涨跌幅 | % | 同上 | 日 | 无 | **S-A 未提供**，本仓库一律自算：`close / close_prev − 1`（见 §4 对齐规则） |
| `index_name` | 指数显示名 | 文本 | — | — | 不为空 | — |
| `source` | 来源标记 | 文本 | — | — | 取值 `A_tencent` / `B_eastmoney` | — |
| `style_tag` | 风格标签（大盘/中盘/小盘/超小盘/科技成长/防御/全市场） | 文本 | — | — | 由代码映射表决定，不从行情推断 | — |

### 单位换算速查

```
S-A volume(股) ÷ 100              = S-C vol(手)
S-C amount(千元) × 1000           = 元
turnover_proxy(元) ÷ 真实成交额(元) = 3.3 ~ 3.6   ← 系统性偏高，只做趋势
```

## 2. 复权方式

| 对象 | 复权规则 | 说明 |
|---|---|---|
| 指数点位（`open/close/high/low`） | **不复权** | 指数本身无除权事件；编制定值不因成分股分红送转而调整 |
| 成交量 `volume` | 不做除权调整 | S-A 的 `qfq`（前复权）参数仅作用于价格字段，成交量按原始口径返回 |
| 腾讯接口的 `qfq` 参数 | 接口层要求 `qfq`，但指数代码返回的点位即编制定值 | **不要**把个股的「前复权」直觉套到指数上 |
| 个股（未来扩展） | 前复权 `qfq`，**且必须记录复权基准日** | 复权因子随新除权事件变化；跨实验比对个股收益必须对齐复权基准日 |

> **规则**：复权方式写进 manifest 的 `sources` 段，随快照一起锁定。换复权方式 = 新快照 = 新 sha256。

## 3. 时点规则

| 规则 | 内容 |
|---|---|
| **数据截止点** | 2026-11-13（原文发布日 2026-11-15 前最后一个完整交易日）。**任何窗口右端 ≤ 2026-11-13**，不使用发布日之后的任何数据。 |
| **区间端点** | 收盘到收盘：`区间末收盘 ÷ 区间初收盘 − 1`，**不含日内**。 |
| **月度窗口** | 「上月末收盘 → 本月末收盘」。非交易日端点取**该日之前最近一个交易日**的收盘。 |
| **节假日** | 2026-10 因国庆休市，实际交易日为 10-08 ~ 10-30；区间计算用「≤ 目标日的最后一个交易日」，不硬编码交易日。 |
| **年化基准** | 年化收益用自然日折算 `(1+区间收益)^(365.25/自然日数) − 1`；**波动用交易日折算 ×√252**。两者不可混用。 |
| **YTD 基准日** | 年初至今 = 2025-12-31 收盘为基准；最大回撤起点同为 2025-12-31。 |
| **原始层只追加** | CSV 快照写盘后不改写；`experiments/<EXP>/` 下的加工层产物可由脚本重建。 |

## 4. 对齐方式

| 场景 | 规则 | 代码 |
|---|---|---|
| **交易日历对齐** | 指数之间按**日期**对齐，不按行号对齐（休市日可能因指数编制规则不同而缺行）。 | `build_analysis.py: close_on(df, ymd)` 取 `index <= ts` 的最后一个 |
| **涨跌幅自算** | `close_t / close_{t-1} − 1`，`t-1` 取**序列内前一个已有交易日**（可能跨节假日），不是「自然日前一天」。 | `build_analysis.py: s.pct_change()` |
| **区间收益** | 端点各自取「≤ 目标日的最后交易日」，端点日期**写入结果**（`start_date` / `end_date`），供审计核对。 | `build_analysis.py: period_return()` |
| **风格相对收益差** | 两个指数**各自**在同一窗口内算收益，再相减（单位：百分点）。不是比两条净值曲线的斜率。 | `build_analysis.py: style_spreads` |
| **成交额月均值** | 按**自然月**分桶求均值（`resample("ME").mean()`），不是按交易日数加权。 | `build_analysis.py: turnover_proxy_month_mean_2026` |
| **跨源校验** | 同日同口径比较**收盘点位**，源A 落盘 2 位小数、源C 原始精度 → 判据用**四舍五入半格**（绝对差 ≤ 0.005），相对差 ≤ 约 1.2e-6。 | `build_analysis.py: cross_check` |
| **基准日选取** | 基准取 `start` **之前**最后一个交易日收盘（`start` 当日若为交易日则含入计算区间）。 | `build_analysis.py: ann_stats()` |

## 5. 停牌与退市处理

**本轮范围：只有指数，没有个股，因此停牌与退市不产生缺口。** 但规则先写死，扩展到个股时直接套用。

| 情形 | 本轮（指数） | 扩展到个股时的规定 |
|---|---|---|
| **停牌** | 不适用（指数连续发布，无停牌） | 个股停牌日**保留行**、价格**前向填充到上一收盘**、成交量置 0；不得删除行（否则区间收益率的日频分母被扭曲）。 |
| **退市** | 不适用（指数会剔除成分，但指数序列本身连续） | 退市股票在退市日**必须保留到最后交易日**；退市后从**次一交易日**起移出股票池。**不得回溯剔除**（那是幸存者偏差）。 |
| **长期停牌（> 停牌阈值）** | 不适用 | 需在实验协议中预先写死阈值与处理方式；处理方式必须对样本内/样本外一致。 |
| **涨跌停** | 不适用（指数点位连续） | 涨跌停日**不得成交**，回测中该日下单量按 0 处理；不得假设能买到。 |
| **新股上市** | 不适用 | 上市首日**排除**（无完整历史），在股票池构建中按「上市满 N 个交易日」过滤，N 须预先写死。 |
| **成分调整** | 指数编制方在生效日一次性调整，**指数点位本身连续**，无需处理 | 若直接用成分股构建组合，则调整生效日**按生效后的名单**建仓，不得提前使用新名单（那是前视偏差）。 |

## 6. 缺失与缺口的记录义务

| 规则 | 内容 |
|---|---|
| 显式记缺 | 取不到的数据写「未取到」，**不用代理指标冒充原始字段**。 |
| 代理须标注 | 用了代理口径（如 `turnover_proxy`），必须在图注、指标表与报告正文三处都写明「代理 + 偏差倍数 + 只适用于趋势」。 |
| 快照缺项留痕 | manifest 里 `ok:false` 的记录保留 `error` 原文（异常类型 + 消息），不删除条目。 |
| 禁止静默补值 | 缺行不补 0、不前向填充、不插值。 |

## 7. 字段级质量门（快照入库前必查）

| 检查 | 判据 |
|---|---|
| 主键唯一 | `date` 在单个指数内唯一 |
| 数值缺失 | `open/close/high/low/volume` 无 NaN |
| 边界日期 | 首行 = 窗口内第一个交易日，末行 = 截止点之前最后一个交易日 |
| 行数一致 | 同批指数行数应相同（451）；不一致需逐条说明 |
| 时间对齐 | 同一日期在不同指数间的口径一致（§4） |
| 异常值 | 点位跳变 > 30%/日 需人工确认是真实事件还是取数错误 |
| 单位 | `volume` 为股、S-C `vol` 为手，跨源比较前必须换算（§1） |
| 快照漂移 | 重算 sha256 与 manifest 逐个比对（`audit/audit_recompute.py` 第 3 节） |
