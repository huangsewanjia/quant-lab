二、公开层能拿到评级/目标价吗？——基本拿不到

四、与中资券商研报（WORK-536）如何合并成一张「研究内容表」

  • 统一主键：(机构, 标题, 发布日期, 原文URL)；统一字段： 语言 / 来源渠道 / 内容类型 / 是否含评级目标价 / 是否二次转述 / sha256 / 采集时间。
  • 两层互补而非重复：外资层补全球视角与宏观框架（观点为主，评级＝无）； 中资层补评级/目标价与 A 股个股覆盖（估值结论为主）。
  • 合并后的净效果：一张表同时覆盖「观点层 + 估值结论层」； 外资层不承担估值结论的补充责任（实测证明它给不了）。
  • 两条必须保留的标记：二次转述（中资平台转载的评级）与 语言（EN/CN）—— 前者决定能否直接使用，后者决定检索与去重口径。

五、限制与未取到（必读）

  1. Reuters / Bloomberg / FT / WSJ 的站点侧行为未测（本机出口不可达，不是站点拒绝）。
  2. HSBC 的 Global Research 条目未逐篇扫描，其正文是否含评级未验证。
  3. Citi / Barclays / 东方财富 / 雪球 / 萝卜投研 / NYSE 的列表未取到（JS 渲染）； 「入口列表需 JS」≠「整站不可采」——Citi 的文章详情页已实测可直接抓（Tokenization 2030，4,017 字符）。
