## 1. 核心假设（一句话）

**在「公开、无需账号、无需付费墙」口径下，外资投行研究内容存在一批可机器采集的公开入口，但其中含评级/目标价的比例极低——公开层能稳定拿到的是「观点/主题内容」，拿不到的是「估值结论」，因此外资研报公开层的机器采集价值主要体现在信息聚合与主题追踪，而非替代付费研报源。**

## 2. 研究对象

- **对象**：外资投行与财经媒体对外公开发布的研究/观点类内容渠道。
- **覆盖范围**：投行官网 13 家（Goldman Sachs、Morgan Stanley、J.P. Morgan、UBS、Citi、BofA、Barclays、HSBC、Nomura、Daiwa、Macquarie、Deutsche Bank、Bernstein）、财经媒体 6 家（Reuters、Bloomberg 公开页、FT 公开页、WSJ 公开页、CNBC、Barron's）、监管/披露 3 类（SEC EDGAR、FINRA、交易所披露）、聚合与社区 7 个（慧博投研、发现报告、萝卜投研、东方财富研报中心、雪球、格隆汇、巨潮资讯）。
- **边界**：只收公开可得层。**不绕过登录、付费墙、验证码、Cloudflare 挑战**；403 就记 403。不注册账号、不订阅、不抓 PDF 全文、不做观点分析。

## 3. 时间窗与数据截止点

- **实测时间窗**：2026-11-23 14:05–16:00（UTC+8）单次快照。
- **数据截止点**：以各渠道页面**自身标注**的发布时间为准；无法取到日期的渠道记「日期未取到」，不以抓取时间充当发布日期。
- **更新频率**：按渠道公开栏目实际发布节奏描述（周更 / 日更 / 不定期），描述性结论，**不外推**。

## 4. 评价指标与判定口径

| 指标 | 判定口径 | 判定值 |
|---|---|---|
| HTTP 可达 | 单次 GET 的状态码 | 200 / 3xx / 403 / 404 / 5xx / 超时 |
| 可解析列表 | 返回体含**可解析的标题 + 日期**（各 1 条真实样例） | 是 / 否 |
| 是否需 JS | 去除标签后可见文本 < 800 字符，或返回体含 "enable JavaScript" 类提示 | 需 JS / 不需 JS |
| 抓取合规 | robots.txt 对该 UA + 该路径是否 Allow | Allow / Disallow / 无 robots |
| 是否含评级/目标价 | 页面**自身**出现 rating / price target / 目标价 字样并能定位到具体条目 | 有 / 部分 / 无 / 未取到原文 |
| 建议 | 依据上述实测结果 | 采 / 观察 / 不采 |

## 5. 可接受的成本与容量假设

- 同一域名 ≤1 请求/秒（脚本内按域名节流）；单轮总请求 ≤200；不做全站爬，只打入口页与少量详情页。
- 单个渠道探测超时 ≤20s；失败即记失败原文，不重试试探。

## 6. 什么结果会推翻假设

- **H1 反证**：公开层可稳定拿到**成体系的个股评级与目标价**（例如某渠道能给出多家可比公司评级 + 目标价 + 时点），则「公开层拿不到估值结论」被推翻。
- **H2 反证**：可直连且无需 JS、无需登录的渠道 **≥10 个**（超过清单的一半），且能覆盖主要外资投行，则「公开层采集价值有限」被推翻。
- **H3 反证**：实测出现「必须绕过付费墙/登录才能取得数据」而本单仍给出结论，则整个口径作废。

## 7. 停止条件

1. 超半数（>14/29）渠道实测为 403 / 需 JS / 需登录 → 公开层采集价值有限，停止加码并如实回报。
2. 任一渠道 robots.txt 明确 Disallow 抓取路径 → 该渠道只做「人工看」，不抓正文。
3. 总请求数达 200 → 停手回报，不做例外。
4. 出现付费墙/登录/验证码绕过需求 → 停手，不绕。

## 8. 本单不做

- 不订阅、不注册账号、不抓 PDF 全文、不做投行观点总结、不做个股评级/目标价/买卖建议。
- 抓到的正文只作内部研究，**不入 public 仓库**；`raw/foreign_research` 不入库。
