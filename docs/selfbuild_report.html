一、一页结论

77 条 P0 里，有可复跑取数脚本的从 2 条（2.6%）变成 27 条（35.1%）。 新增的 25 条全部是 B 类「近似替代」，不改变 541 的 A/B/C 判定——脚本让代理可执行、可复现、可维护， 不是把 B 洗成 A。C 类 16 条一条没动（仍是只能买）。

  • 做法：先按 5 条判据（影响判断 → 代理质量 → 成本 → 可维护 → 硬缺口倾斜，按序）把 20 条候选筛到 10 条； 每条一个单文件脚本，仅标准库，支持 --start/--end、主键合并幂等、同域 ≤1 req/s、失败非 0 退出。
  • 10 条里有 3 条属 16 条「需采购」硬缺口（存储现货价、锂/电芯价格指数、全球储能出货）；其余 7 条服务宏观、欧洲贸易、交易所行情与欧洲储能。
  • 医药线 0 条入选——这是本轮最硬的一条限制：公开层只有 PDF 表（IFPMA/EFPIA/USGS 式）与供给侧代理（openFDA 件数）， CMS 出口 403、openFDA 单页实测 298 s。台账里 8 条医药行逐条写了触发条件，不硬凑。
  • 仍未解决：B 类代理与原指标的偏差校准（n=25 条都没做），以及全历史回补（本轮窗口只到本期）。
和 541 的关系：541 判「能不能近似」，本轮判「值不值得现在做、做了怎么入库」。 541 的 Top-5 脚本（trendforce / benchmark / sne / exchange / ppi）中有 4 个在本轮被重写为标准库单文件并补齐增量契约， 另新增 6 个数据集（Eurostat / OWID EV / OWID 能源 / World Bank / IRENA / EMMES）。541 的旧落盘里，trendforce_spot_price 的原件留在 raw/industry_alt/trendforce_spot_price/legacy-541/；benchmark / sne / exchange 三个目录的旧 data.csv（列结构不同）已被本轮同主键数据覆盖，541 的 sha256 对这三条不再可复现——这是本轮唯一一处不可逆的产物替换， 交易数据本身未丢（覆盖范围更大）。ppi_spot_prices、comtrade_trade_values、ow_iea_usgs_timeseries 三个 541 目录本轮未触碰。

七、限制（引用结论时必须一并引用）

  1. 脚本让代理可执行，不让代理等价：25 条 B 类与原指标的偏差未做校准，直接当原指标用会失真（例如 Benchmark 只有指数点、Eurostat 只有 SITC 大类）。
  2. 窗口只到本期：--start/--end 支持回补，但本轮未做 5–10 年历史对齐（541 的 L2 限制未消除）。
  3. 快照型数据没有历史：TrendForce / Benchmark / EMMES 是页面快照，只能日更累积；回溯不到过去。
  4. 部分源为单点抓取：SNE 列表页只回最近 12 条，早于列表窗口的稿件需人工给 release_id。
  5. IRENA 储能只有抽水蓄能；GFEX/SHFE 没有注册仓单；二者都不能替代「全球仓单」与「电化学储能」。OpenFDA 未入选，医药线没有脚本。
  6. 本报告不含行业结论、评级或目标价；数据仅供内部研究。
