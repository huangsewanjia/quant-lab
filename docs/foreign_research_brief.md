# 外资研报公开层 · 渠道清单与可抓性实测（一页结论）

**测量日期**：2026-11-23（UTC+8） · **样本**：29 个渠道 · **请求总量**：185 次（上限 200） · **口径**：公开、无需账号、无需付费墙；不绕过登录/验证码/robots

## 一句话结论

**外资投行的研究内容在公开层「能看、但机器只能拿到观点，拿不到评级与目标价」**——29 个渠道里 13 个可直接机器采（投行官网 7 个、中文聚合与社区 4 个、监管与财经媒体各 1 个），但 9 篇真实文章正文的全文扫描里，**外资投行的评级/目标价命中 0 次**；公开层的价值是**全球视角与主题框架**，估值结论必须另找来源。

## 一、哪些能机器采，哪些只能人工看

| 结论 | 渠道 | 说明 |
|---|---|---|
| **能机器采（13）** | Goldman Sachs Insights、Morgan Stanley Ideas、J.P. Morgan Insights、BofA Institute、HSBC GBM Insights、Macquarie Insights、dbInsights（德银）、CNBC Investing、SEC EDGAR（公开 JSON）、慧博投研、发现报告、格隆汇、巨潮资讯 | 入口列表页在 HTML 里就能解析出「标题+日期」，正文详情页可直接抓（已抓 9 篇样例，字符数 2,742–26,064，sha256 齐） |
| **只能人工看（14）** | 列表需 JS 渲染（8）：Citi Institute、Barclays、Nomura、Daiwa、NYSE、萝卜投研、东方财富研报中心、雪球；403（1）：UBS；落地登录页（1）：Bernstein；本机出口不可达（4）：Reuters、Bloomberg、FT、WSJ | 内容公开存在，但机器在列表层拿不到 |
| **不采（2）** | Barron's（robots.txt 对 `*` 为 Disallow）、FINRA（robots.txt 不可读，HTTP 403） | 合规侧不应抓，本单**未发正文请求** |

**要点**：四个欧美大媒体（Reuters/Bloomberg/FT/WSJ）在本机**网络层不可达**（DNS 返回污染地址、IPv6 无路由，
连 robots.txt 都取不到，`fetch` 服务侧同样失败）——这是**本机出口问题，不是站点拒绝**，不能据此说这些站点不可抓。

## 二、公开层能拿到评级/目标价吗？——**基本拿不到**

- **列表页全文扫描**：13 个直连渠道里 11 个全文 **0 次**出现 price target / 目标价 / 评级 / 增持 / 减持 等字样；
  2 个出现的（格隆汇、巨潮）字样来自**转载与公告原文**。
- **正文全文扫描（9 篇）**：5 篇外资投行文章（GS / MS / JPM / 德银 dbInsights / HSBC）+ Citi + CNBC + 发现报告 → **命中 0 次**。
  唯一疑似命中的 JPM 样例 `underperform`，上下文是「债券市场**跑输**其他发达市场国债」，不是个股评级。
- **唯一含完整「评级+目标价」的样例来自中资转述**：格隆汇转载国盛证券对富特科技的首次覆盖
  （评级×14、增持×5、目标价×3）——**是二次转述，不是外资投行的原始评级**。

> **结论**：公开层能稳定获取的是**主题观点、宏观与行业判断**（GS 全球增长预测、JPM 国债收益率、
> 德银海洋公地研究、HSBC 电气化融资），**不能**作为评级/目标价的来源。

## 三、建议的采集频率

| 集合 | 建议 | 实测依据 |
|---|---|---|
| 13 个直连渠道 | **每周一次增量** | 实测相邻日期间隔中位数：HSBC 5 天、JPM 7 天、德银 7 天、慧博/发现报告 3 天 |
| CNBC、SEC EDGAR | 每日或每 2 日（可选） | 实测 1 天 / 4 天 |
| 需 JS / 403 / 登录的 10 个 | 人工看，或换出口/换渲染方案后重测 | 机器采不到 |
| Barron's、FINRA | 不采 | robots 禁 / robots 不可读 |

**总量**：按每周一次，投行与中文层约 **26 次/周**（13 渠道 × robots+列表），远低于 200 次上限。

## 四、与中资券商研报（WORK-536）如何合并成一张「研究内容表」

- **统一主键**：`(机构, 标题, 发布日期, 原文URL)`；统一字段：
  `语言 / 来源渠道 / 内容类型 / 是否含评级目标价 / 是否二次转述 / sha256 / 采集时间`。
- **两层互补而非重复**：外资层补**全球视角与宏观框架**（观点为主，评级=无）；
  中资层补**评级/目标价与 A 股个股覆盖**（估值结论为主）。
- **合并后的净效果**：一张表同时覆盖「观点层 + 估值结论层」；
  **外资层不承担估值结论的补充责任**（实测证明它给不了）。
- **两条必须保留的标记**：`二次转述`（中资平台转载的评级）与 `语言`（EN/CN），
  前者决定能否直接使用，后者决定检索与去重口径。
