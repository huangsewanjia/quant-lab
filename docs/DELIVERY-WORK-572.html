3 怎么回滚

回填前的 19 张行业表已快照到 raw/_backup-work572/db-pre-work572/（2026-11-25 17:05，行数见快照 _meta.json）。回滚只需在库锁下按表恢复：

cd /srv/share/quantdb/code/quant-lab
QUANTDB_HOME=/srv/share/quantdb PYTHONPATH=$PWD \
  flock -w 1800 /srv/share/quantdb/logs/.quantdb-db.lock \
  /home/moyongkai/.venvs/quantdb/bin/python - <<'PY'
import duckdb, glob, os
con = duckdb.connect("/srv/share/quantdb/db/quantdb.duckdb")
for p in sorted(glob.glob("/srv/share/quantdb/raw/_backup-work572/db-pre-work572/*.parquet")):
    t = os.path.basename(p)[:-8]
    con.execute(f"DELETE FROM {t}")
    con.execute(f"INSERT INTO {t} BY NAME SELECT * FROM read_parquet('{p}')")
PY

抓取代码回滚：本次改动集中在 code/industry_fetch/*.py 与两个国际 fetcher；这些文件不在 git 里， 按 §6 的摘要核对，需要退回时按 docs/industry-ingest-2026.md §10.2 的「改了什么」逐条还原（唯一结构性改动是 LPR 接口参数与 OWID 全序列）。raw 为合并写，回填前的旧行仍在 parquet 内。

4 遗留与需要确认

  • 能源局（nea_power）未达 60 期：站内搜索限速 + 深分页不稳定；「全国电力统计数据」正文数据表是 PNG 图片， 结构化需 OCR（不在本单范围）。已取到的期间见覆盖表，未取到的按「上游只给近 N 年 / 限速 / 图片表」分层登记。
  • GFEX 1,000 个交易日不可达：碳酸锂 2023-07-21 才上市，上游最早只有该日（实测 2023-01-03 无碳酸锂行）。
  • 财政部 §4.3 串期缺陷原样保留：2017-11 那批行未修，按原处置只做日期域检查。
  • 6 个快照/新闻源未回填：上游只给当日/当年值，无历史序列。
