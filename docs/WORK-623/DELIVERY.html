5主流程控件说明

本通道只有命令行与一个只读清单页，没有自建 Web 应用。下面对实际存在的入口逐项说明。

控件 / 入口位置行为与可见结果
fetch --dry-run桌面机终端只读：打印/写 dry_run_report.json，含登录态、robots 判定、详情页 meta、控件候选选择器计数；不点击、不落 PDF。
fetch桌面机终端逐条打开详情页 → 点下载 → 存为规范文件名；成功打印「N 页 → 路径」，失败写 failed.jsonl 并在 _diagnostics/ 留页面快照。
--selector命令行参数覆盖默认选择器列表；默认列表见 DEFAULT_SELECTORS（button:has-text("下载")、a:has-text("下载")、[class*="download"]、[data-testid*="download"]；指向 robots 禁止路径的控件点击前会被拦下并写失败）。
sheet 生成的清单页sheet.html顶部 4 步说明；搜索框按标题/机构即时筛选；每行「标题链接→详情页」「机构」「页面日期」「收编后文件名 + 复制按钮」。断网可读，无外链资源。
站点「下载」按钮fxbaogao 详情页本站控件，非本通道实现；匿名状态下不渲染（实测匿名页无下载链接）。本通道只负责点它并收文件。
ingest / checksMo-server 终端输出一行 JSON 统计（scanned/inserted/unchanged/failed/changes）与 C1–C7 的 PASS/FAIL + 计数；退出码非 0 表示有阻断项。

8数据口径与幂等

唯一键
report_id（发现报告 detail 数字 id）；同 id 重抓覆盖不新增
内容变更
sha256 变化 → 先写 report_fulltext_changes（old/new/时间/原因），再覆盖正文行
入库校验
meta 字段齐 → sha256 对磁盘 → 字节数对磁盘 → pypdf 页数 >0 且与 meta 一致；任一不过写 failed.jsonl，不入库
关联口径
标题归一相等 + 机构归一相等 + |发布日差| ≤ 3 天；归一化只在 SQL 宏里定义
多候选
日差最小 → info_code 最小；candidate_count 暴露歧义，不隐藏
请求节流
同域名 ≥1.05 s（按完成时刻）；单轮 --max-requests 默认 200；全部请求进 request_ledger.json

9已知限制

  • 真实链路未验证：Playwright + CDP 下载、真实下载控件选择器、真实额度/风控阈值，全部要等登录态；本机 Playwright 也未安装（ModuleNotFoundError）。
  • 关联率是机制值不是实测值：彩排 100% 来自合成样本，真实报告与 report_meta 的重合度尚未测。
  • 手工收编依赖 PDF 文字层：扫描版 PDF 首页无文字时 adopt 会判 unmatched，需要人工按 report_id 命名后直接 ingest。
  • 机构名口径差异：媒体/研究院类报告在 report_meta 里没有对应机构，必然未关联；这属预期，见 v_report_fulltext_unlinked。
  • Windows 落盘根：默认根是 POSIX 路径，桌面机必须设 FXBAOGAO_ROOT（或传 --root），否则会落到 C:\srv\...，Mo-server 扫到 0 篇。
  • 旧样例与新目录并存：WORK-537 的公开层样例在 raw/foreign_research/fxbaogao/，与本单 raw/reports_fulltext/ 是两套资产，不要混用。
