8数据口径与幂等

唯一键
report_id（官方 reportId）；同 id 重抓覆盖不新增
成功判定
HTTP 200 且 body.code ∈ {0,200}；HTTP 200 + code=300011 判失败
内容变更
sha256 变化先写 report_fulltext_changes，再覆盖正文行
入库校验
meta 字段齐 → sha256/字节/pypdf 页数/report_id 与文件名一致；任一不过写 failed.jsonl
回查链接
site_url = https://www.fxbaogao.com/view?id=<id>，meta 缺省时入库按 id 补齐（官方要求）
重复扣额度防护
同 id 已存在默认跳过；--force 显式重下
关联口径
标题归一相等 + 机构归一相等 + |发布日差| ≤ 3 天；归一化只在 SQL 宏
